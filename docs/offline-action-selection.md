# 저장 모델로 M2 행동 후보 선택하기

[첫 예측 학습 결과](evidence/2026-10-31-first-action-prediction.md) · [시각 행동 학습](visual-action-learning.md)

`learning/joint_action_selection.py`는 이미 학습한 모델에 현재 영상상 상대 방향·속도와 후보 명령을 넣고, 4초 뒤 목표에 가장 가까울 것으로 예측되는 후보를 고른다. 저장 자료만 읽는 `tools/replay_joint_action_selection.py`를 제공한다. 재학습, 장치 접근, 촬영, 명령 전송, W&B 연결은 없다.

## 선택 규칙

후보는 M2 위·아래 × 요청 700·900ms의 네 개이며 PWM 크기는 160이다. 실제 출력을 일정 PWM으로 가정하는 모델은 아니다. 모델은 첫 실측 때의 램프와 지연을 포함한 결과를 학습했다.

1. 모델·데이터셋 스키마와 데이터셋의 정규 JSON SHA-256 연결을 검사한다. 저장 모델의 정규화가 학습 16개 입력에서 나온 값인지 확인하며 모델을 다시 적합하지 않는다. 이 검사는 기존 원본 심사를 대신하지 않는다.
2. 관측이 유효하고 정착했다는 입력 확인이 필요하다. 이 플래그는 호출자가 제공한 관측 심사 결과이며 선택기가 카메라를 새로 검사하는 것은 아니다. 같은 투영 좌표계·구도를 전제로 한다.
3. 시작 상대 방향은 **각 명령의 학습 입력 최솟값~최댓값**, 속도는 **전체 학습 입력의 최솟값~최댓값** 안이어야 한다. 검증·시험 상태를 사용해 범위를 넓히지 않는다. 후보별 제외 이유를 남긴다.
4. 각 후보의 예상 끝 상대 방향과 목표 절대오차를 계산한다. 예상 끝 방향과 목표는 기존 투영 관측 구간 −10~24° 안에서 다룬다. 이는 물리 관절 한계나 충돌 방지 범위가 아니다.
5. 유효 후보가 있으면 목표 오차가 가장 작은 후보를 고른다. 정확히 같은 오차면 짧은 기간, 그다음 고정된 방향 순서로 결정한다. 현재 오차가 허용오차 이내이거나 모든 후보가 현재보다 나쁘면 `hold`를 반환한다. 기본 허용오차 1°는 사용자가 바꿀 수 있는 목표 판정값이며 학습된 신뢰구간이 아니다.
6. 관측 이상·속도 범위 이탈·유효 후보 없음은 `abstain`이다. `hold`도 무변화 가정의 비교 결과일 뿐 실제로 4초 동안 정지함을 측정한 결과가 아니다. 어떤 결과도 실물 실행 권한을 부여하지 않으며 `controlEligible=false`를 유지한다.

시작 각도와 속도를 각각 검사하는 주변 범위는 그 조합의 학습 관측 여부까지 보장하지 않는다. 두 시작 구간 사이 보간, 명령별 속도 차이, 작은 데이터의 불확실성이 남는다. 점 예측으로 한 단계만 비교하며 확률적 안전 보증이나 다단계 목표 도달 보장을 제공하지 않는다.

## 로컬 사용

이미 심사한 데이터셋과 그 데이터에 연결된 첫 모델 파일을 비공개 경로에 둔다. 아래 경로는 예시이며, 기존 원본이나 결과를 출력 경로로 지정하지 않는다.

```sh
python3 tools/replay_joint_action_selection.py \
  --model .local/first-prediction/model-and-evaluation.json \
  --dataset .local/first-prediction/audited-dataset.json \
  --split test --goals -5 0 5 10 15 20 --tolerance-deg 1 \
  --output .local/offline-selection/replay-01.json

python3 -m unittest tests.test_joint_action_selection tests.test_joint_collection_prediction
```

기존 출력 파일은 덮어쓰지 않는다. JSON에는 시작 상태·목표, 네 후보의 예상 변화·끝 방향·목표 오차·제외 이유, 선택 또는 보류 사유, 모델·데이터셋 해시가 들어간다. 보고서도 비공개로 보존한다. `--execute`나 장치 주소 인자는 없으며, 결과의 후보 설명은 기존 장치 실행기의 명령 페이로드가 아니다.

## 첫 저장 자료 적용: 2026-10-31

기존 시험 상태 8개 각각에 목표 −5, 0, 5, 10, 15, 20°를 넣어 **48개 오프라인 판단**을 확인했다. 목표를 바꾸어 같은 상태를 재사용한 것이므로 독립 실물 표본 48개가 아니다. 모델 재적합과 새 실물 명령은 0회이며 원본 데이터셋·모델의 파일 해시가 유지됐다.

| 결과 | 판단 수 | 해석 |
|---|---:|---|
| 후보 명령 선택 | 28 | 모델 점 예측에서 목표 오차가 무변화보다 작음 |
| `hold` | 8 | 5개는 허용오차 이내, 3개는 개선 예측 없음 |
| `abstain` | 12 | 시작 상태 2개가 모든 명령의 학습 각도 범위 밖; 각각 목표 6개 |

예를 들어 시작 약 4.258°에서 목표 10°는 위 900ms를 선택했고 예상 끝 방향은 약 11.549°였다. 시작 약 9.413°에서 같은 목표는 현재 오차가 1° 이내라 `hold`였다. 이는 저장 상태에서 계산한 선택이며 새 명령을 실행한 결과가 아니다.

선택한 명령이 당시 실제 실행 명령과 같은 경우만 `selectedObservedGoalErrorDeg`를 연결한다. 이번에는 7개 판단이 일치했으며 서로 다른 원본 전이는 5개다. 나머지 후보와 `hold`의 실제 결과는 알 수 없어 `null`로 남긴다. 일치한 표본도 선택 편향이 있으므로 이 부분집합으로 정책 성공률이나 무작위 정책 대비 개선을 계산하지 않는다. 전체 `policySuccessRate`도 `null`이다.

이미 예측 평가에 사용한 시험 자료를 다시 살펴본 탐색적 분석이다. 새로운 독립 정책 시험이 아니며, 이 결과로 규칙을 바꾼다면 이후 새 실측 평가 집합이 필요하다. 후속 단일 목표 시험 연결은 아래와 같이 모의 검증했다. 다음 단계는 별도 실물 범위에서 목표 오차가 실제로 줄어드는지 확인하는 것이다.


## 관측→선택→단일 목표 시험 연결

`learning/joint_goal_trial.py`의 `SingleGoalTrial`은 새 범위의 해시 확인을 받은 뒤 카메라·실행 어댑터를 통해 한 번만 시험한다. 기본 경로에서 장치를 찾거나 명령을 보내는 공개 CLI는 추가하지 않았다. 실제 현장 어댑터와 장치별 설정은 별도로 관리한다. [첫 실물 단일 목표 접근](evidence/2026-10-31-first-model-goal-approach.md)에서 한 명령의 결과를 측정했다.

- 명령 전 −0.9~−0.1초의 유효·안정 관측 최소 5개, 시간 폭 0.5초로 상대 방향 중앙값과 속도를 계산한다. 입력과 최신 관측이 모두 정착해야 한다.
- 초기 선택이 `hold`/`abstain`이면 실행 어댑터를 호출하지 않는다. 선택한 경우에도 실제 전송 직전에 다시 계산한다. 처음 큐에 넣은 명령이 현재 입력 범위 안에서 여전히 무변화보다 목표 오차를 줄일 때만 실행한다. 작은 속도 추정 변화로 최선 후보의 순위만 바뀌면 큐를 교체하거나 중단하지 않고, 당시 최선 후보와 실제 유지한 후보를 모두 기록한다. 유지/보류 전환, 원래 후보의 적격 상실·개선 소실은 중단한다. 결정 저장 뒤 최신 관측의 정착·유효성·0.5초 이내 나이를 다시 확인하고, 결정 후 0.25초가 지나면 보내지 않는다.
- 한 범위에서 허용하는 것은 M2·PWM 크기 160·700/900ms 중 최대 한 명령이다. 촬영 예산은 30초·320프레임이며 자세 맞춤·실패 명령 자동 재시도·다음 목표 반복은 없다. 새 시험은 새 원본 디렉터리와 구체적인 별도 범위를 사용한다.
- 현장 어댑터는 최초 읽기에서 현재 부팅 ID를 고정하고, IDLE·전체 OFF·빈 큐를 확인한다. 기존 큐를 임의로 지우고 시작하지 않는다. 단일 시퀀스·ARM·실행 뒤 STOP과 전체 OFF, 출력 이력의 M2 방향·크기를 검증한다. 조회·POST·STOP에는 0.5초 기한을 적용하며 첫 쓰기 전 읽기만 최대 2초다. 호스트 기한은 물리적인 이동 상한 보증이 아니다.
- 명령 시작 +3.75~+4.25초의 안정한 최소 3프레임으로 실제 끝 방향을 측정한다. OFF 확인이 이 창보다 앞서야 한다. 정착이 늦어져도 라벨 창을 뒤로 이동하지 않는다. 실제 목표 오차 감소, 1° 등 범위에 지정한 목표 허용오차 만족 여부, 모델 예측 오차를 구분한다.
- 응답 유실·추적 소실·저장 오류·인터럽트에는 다음 명령 없이 정지·OFF 확인을 먼저 처리한다. 결과 불명은 성공으로 기록하지 않는다. 모델 자체의 `controlEligible=false`는 유지하며, 새 시험의 명시적 범위가 제한 실행의 근거다.

이 코어의 성공 상태 `measured`는 단일 행동과 고정 시점 측정을 완료했다는 뜻이다. 목표 달성은 별도 `goalReached`, 오차 감소는 `goalErrorReduced`로 기록한다. 첫 실측에서는 M2 위 900ms 요청 1회로 목표 오차를 5.479°에서 0.967°로 줄였다. 앞선 구동 전 중단 3개와 함께 보고하며, 단일 성공이나 소프트웨어 테스트를 반복 정책 성능으로 해석하지 않는다.

## 고정 모델 반복 평가 실행기

`learning/joint_goal_evaluation.py`의 `GoalEvaluation`은 기존 모델을 고정하고 모델 선택·고정 700ms 명령·무출력 유지의 세 방법을 비교한다. 최초 반복 평가 시도는 시작 자세 맞춤 중 중단됐고 목표 평가 결과는 아직 없다. 아래는 수정한 실험 계약이다.

- 영상상 시작 구간 3.2~7°에서 목표 10°, 7~10.7°에서 목표 4°를 사용한다. 각 구간·방법을 2회씩 배치해 계획 분모는 12개다. 첫 촬영은 모델→고정→유지 순서, 다음 촬영은 유지→고정→모델 순서이며 각 방법 안에서는 높은 구간과 낮은 구간을 번갈아 사용한다. 같은 날의 소표본 비교이며 무작위 배정에 의한 인과 효과 검증은 아니다.
- 시작 구간 맞춤은 목표 평가 명령과 별도 기록한다. PWM160·550/700/900ms, 조건당 최대 3회이며 전체 최대 36회다. 목표 평가 명령은 모델·고정 방법에서 합계 최대 8회, PWM160·700/900ms다. 무출력 유지는 목표 명령을 보내지 않는다. 전체 명령 시도 상한은 44회이며 불명확한 응답도 시도 예산을 소모한다.
- 촬영은 150초 2회·1920×1080·최대8fps·각1220프레임이다. 원본 상한은 총2440프레임·약20.24GB다. 시작 입력 −0.9~−0.1초에서 최소5개·0.5초 폭, 결과 +3.75~+4.25초에서 안정한 최소3개라는 시간창은 유지한다. 낮은 표본율에서도 필요한 실제 관측 수를 만족해야 한다.
- 같은 캠페인 안에서 다음 촬영의 참조는 직전 완결 촬영의 마지막 검증 이미지와 동일한 점ID 위치로 인계한다. 원본 해시와 참조 좌표를 보존하고 시작 등록을 다시 검사한다. 실행 중 점 제거·재탐지는 하지 않는다.
- 모터 명령의 응답 유실은 `outcome_unknown`으로 기록한다. 미전송·실행 확인·실행 여부 불명과 마지막 OFF 확인은 별개다. 명령 사이 및 결과 관측 구간의 예상하지 못한 출력은 측정을 무효화한다. 오류가 나면 나머지를 `not_started`로 남기고 자동으로 재시작하지 않는다.
- 무출력 기준선도 실제 4초 후 결과를 관측한다. 방법별 계획/측정/목표 도달 수와 보류·중단·미시작·실행 여부 불명을 집계하고, 시작 구간별 계획/측정/목표 도달 수·평균 목표 오차/감소량·실제 시작 방향을 함께 기록한다. 서로 다른 명령의 관측되지 않은 결과를 가상 정답으로 채우지 않는다. 시작 구간 안에서도 실제 자세가 다를 수 있으므로 단순 평균 차이를 확정적인 우열로 해석하지 않는다.

실행기는 카메라·포트·저장소를 주입받으며 공개 모듈 자체에는 장치 검색이나 네트워크 연결이 없다. 실제 연결·범위 확인, 원본 공간 확인, 현장 어댑터 검증은 실물 실행에 필요하다. 이 평가는 모델 재학습이나 기존 시험 세트 점수 갱신을 수행하지 않는다.

초기 4~6°/8~10° 구간은 폭2°로, 실제550ms 맞춤의 약3.056°·3.248°·3.565° 변화보다 좁았다. 첫 구간 진입 과정에서10.867°→7.811°→11.058°→7.494°로 넘나들어 맞춤3회 뒤 종료됐다. 목표 명령0회·평가0개, 나머지11개는 미시작이며102프레임의 부분 촬영을 보존했다. 수정 구간은 관측된 맞춤 변화보다 넓고 고정700ms 후보의 학습 입력 범위 안에 있다. 900ms 후보가 지원되지 않는 가장자리에서는 모델이 해당 후보를 사용하지 않는다. 이 폭은 향후 맞춤 성공 보증이나 동일 자세 보증이 아니며, 구간 변경 전 중단도 전체 평가 이력에서 제외하지 않는다.

이번 수정안의 초기 참조는 중단 촬영에서 메타데이터·해시·동일18점의 유효성이 확인된 마지막 프레임이다. 개별 참조 프레임의 검증과 촬영 전체의 완결 여부를 구분한다.
