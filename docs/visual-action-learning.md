# 영상과 명령으로 배우는 로봇 동작

[프로젝트](../README.md) · [연구 근거와 적용 판단](research/visual-action-learning.md) · [문서·실험 증거 색인](README.md)

MotionBrain의 목표는 로봇팔이 현재 영상과 예정 명령으로 움직임의 결과를 예측하고, 후보 결과를 비교해 물체에 접근·접촉·들기까지 이어가는 것이다. 수집용 사람이 정한 명령, 학습 모델의 선택, 출력 제한과 현장 확인을 구분한다. 모든 관절이나 동시 복합 동작의 학습을 첫 집기의 선행 조건으로 두지 않는다.

## 현재 단계 (2026-11-08)

| 대상 | 확인한 범위 | 남은 경계 |
| --- | --- | --- |
| 현재 자세의 M1 닫기 | 원호·턱 특징의 새 관측 계약으로 전이 4건(열기 2·닫기 2)을 학습하고 모델 고정 | 고정 후 평가 0건, 모델 선택 닫기 0회. 준비 동작 뒤 입력 범위·관측 품질을 통과하지 못해 중단 |
| 짧은 M4 위 방향 | 같은 물체를 사람이 미리 파지한 조건에서 새 4건 학습·고정 후 새 2건 평가 | 상승량 MAE 2px로 명령 평균 기준 2px와 동률. 이 새 모델의 선택 실행 0회 |
| 닫기→들기 연결 | 고정 M1 닫기, 새 접촉 확인, 고정 M4 선택을 잇는 제한 코어 구현 | 연결 실물 실행 0회. 현재 모델로 전체 집기·들기가 완료된 상태가 아님 |

이번 M1 묶음의 실물 명령은 수집 4회와 준비 열기 3회, 총 7회다. 정상 출력 종료와 관측 적격은 별개이며, 마지막 준비 명령은 출력 OFF를 확인했지만 사후 턱 대응점이 모호해 실패로 남겼다. 재학습·범위 클램프·품질 기준 완화로 후속 명령을 강제하지 않았다. 분모·원래 실패와 새 계약 재감사·마지막 관측의 한계는 [닫기→들기 연결 실험 기록](evidence/2026-11-08-close-lift-integration.md)에 정리한다.

과거 M2 모델의 단일 목표 접근은 [별도 실측](evidence/2026-10-31-first-model-goal-approach.md)이며 반복 제어·파지 성능과 구분한다. 과거 650ms M4 모델의 선택 들림은 [들림 관측과 실행 실패의 구분](m4-up-commissioning.md#2026-11-07-고정-모델-선택-들림과-실패-구분)을 따른다. 그 결과를 새 500ms 모델이나 닫기→들기 연결의 성공으로 옮기지 않는다.

## 관측과 예측을 연결하는 구조

```text
현재 영상·사용 가능한 상태 + 예정 후보 명령
                    ↓
        후보별 다음 상태 예측과 정지 비교
                    ↓
       지원 범위 안의 명령 하나만 실행
                    ↓
     출력 OFF → 새 관측 → 실제 결과 평가
```

모델은 명령 뒤의 실제 상태를 예측한다. 예측한 다음 상태를 실제 관측처럼 사용해 다음 단계를 진행하지 않는다. 정지·보류가 선택되거나 관측이 불명확하면 원본과 이유를 남긴다.

| 자료 | 현재 역할 | 혼동하지 않을 것 |
| --- | --- | --- |
| 집게 위 영상 | 물체 기준점과 양턱의 상대 위치·턱점 거리를 측정 | 투영된 픽셀 간격은 물리 개구폭·깊이·접촉력이 아님 |
| 외부 카메라 | 팔·물체·탁자 관계, 팔 표식과 들림 결과 검토 | 박스 중심이나 한 장의 사진만으로 파지 깊이·공중 보유를 확정하지 않음 |
| 예정 명령 | 관절·방향·출력·요청 시간 또는 해당 실행기의 목표값 | 사후 출력 이력을 사전 입력으로 사용하지 않음 |
| 실제 출력·사후 영상·센서 | 실행 여부·정답·종료와 예측 오차의 근거 | 정상 명령 완료와 학습 제어 성공을 동일시하지 않음 |

M1은 세 픽셀 상대 상태의 명령별 릿지 모델을, 현재 짧은 M4 들기는 후보별 평균 변화를 사용하는 국소 전이 모델을 사용한다. 센서 변화량·물체와 턱의 상대 좌표·물체 없는 팔 표식은 각각 다른 관측 계약이다. 서로 다른 카메라·자세·하중·점 정의의 자료를 자동 혼합하지 않는다. [상대 상태 모델](relative-action-selection.md), [팔 표식 모델](projected-arm-learning.md), [수집 원본 계약](manual-data-collection.md)에서 각 경로를 설명한다.

등록한 특징 대응이나 원호 추출은 현재 구도용 관측 도구다. 관측 정확도·접촉 판별의 검증을 대신하지 않으며, 모호한 대응을 제외한 뒤 유리한 표본만 성과 분모에 남기지 않는다. [등록 특징과 원호 관측 계약](model-grasp-trial.md#등록-특징과-원호를-사용하는-새-관측-계약)을 모델 파일·입력 범위와 함께 고정한다.

## 전체 팔에서 기구학·동역학을 쓰는 방법

전체 팔의 URDF와 [정기구학·역기구학 계산](../ros2_ws/src/motionbrain_ros_bridge/motionbrain_ros_bridge/motionbrain_kinematics.py)은 구현돼 있다. 링크·축·좌표계의 모델을 계산하거나 표시하는 것과 실물의 끝단 위치를 정확히 아는 것은 다르다. M4 센서와 별개로 다른 관절의 실제 각도, 링크 치수·영점과 카메라 좌표계의 보정이 충분하지 않다. 미측정 관절을 0으로 채워 전체 팔 자세나 들림 높이의 실측값으로 사용하지 않는다.

기구학은 우선 관절·공간 제약과 도달 가능 후보를 검토하는 데 결합한다. 실제 상태와 좌표계가 확인된 뒤 역기구학으로 접근 자세 후보를 만들고, 학습한 명령 반응으로 그 후보에 접근하는 구조로 확장한다. 두 카메라의 접촉·지지 검토와 기존 출력·각도 제한은 별도로 유지한다.

현재 동작 예측은 관측 상태와 명령 사이의 국소 관계다. 질량·관성·토크·마찰·접촉력을 식별한 전체 팔 동역학이나 역동역학 제어는 구현·검증하지 않았다. 실제 램프 출력, 직전 방향·정지 대기·자세·하중을 기록해 단순 기준선과 비교해야 한다. 움직임이 작았다는 사실만으로 마찰·유격·기계적 한계 중 하나를 원인으로 확정하지 않는다.

## 첫 성공 이후의 진행 계획

다음 단계는 전체 팔의 순차 집기·들기를 기준으로 판단한다.

### 단계와 판단 기준

| 순서 | 수행할 일 | 완료 판단 |
| --- | --- | --- |
| 관측·적용 범위 | 현재 물체와 턱을 안정적으로 구별하고 실제 닫기 입력이 지원되는 관측·모델 마련 | 거절·가림·미평가를 포함한 새 자료와 명시한 적용 범위. 더 많은 M1 명령 자체를 목표로 삼지 않음 |
| 닫기 평가 | 모델을 고정하고 사전 예측을 저장한 뒤 별도 새 동작 평가 | 명령 평균·무변화 기준과 오차 비교, 새 학습과 평가의 분리 |
| 첫 순차 연결 | 모델 선택 닫기→새 두 카메라 접촉·탁자 지지 확인→M4 모델 선택 들기 | 정상 종료와 별도로 공극·보유·실패를 검토한 연결 실측 |
| 접근·정렬 확장 | 배치가 달라져 필요한 경우에만 M5·M2·M3 등의 관절 자료를 해당 조건에서 보강 | 필요한 관절의 순차 목표 접근과 관측 범위 연결. 동시 구동은 별도 과제 |
| 반복 과제 | 시작 자세·물체·하중·날짜를 분리한 보류 평가와 전체 작업 반복 | 접근·접촉·들기 각각의 성공·실패·중단 분모와 일반화 한계 |

M2 원인 분석이나 모든 관절의 학습 완료를 첫 순차 집기의 필수 조건으로 두지 않는다. 반대로 현재 입력이 범위 밖인 상태를 손으로 맞추거나 명령을 대신 선택해 학습 제어 성공으로 보고하지 않는다. 수집·준비용 수동 명령은 별도 기록한다.

## 강화학습과 도구 도입의 위치

현재는 상태 변화의 지도학습과 고정 모델의 후보 비교를 하고 있다. 보상으로 정책을 최적화하는 강화학습이나 전문가 행동을 복제한 집기 정책은 아직 학습하지 않았다. 먼저 고정 평가와 제한된 모델 선택 제어의 기준 결과를 확보하고, 재설정·보상·관측 실패 처리와 반복 가능한 과제를 정한 뒤 잔차 제어·모방학습·강화학습을 비교한다. [연구 근거](research/visual-action-learning.md)의 방법을 현재 장치의 검증 성능으로 취급하지 않는다.

다음 도구는 M1·M4 각각이 아니라 전체 팔의 관측·실험·모델을 대상으로 한다.

| 도구 | 현재 기반과 가까운 도입 범위 | 후속 조건과 목적 |
| --- | --- | --- |
| RViz | URDF·좌표축 표시 기반이 있음 | 실측·추정·미측정을 구분한 전체 팔 상태와 목표·도달 후보 표시. 표시값을 실측 자세로 바꾸지 않음 |
| Rerun | 원본을 감사해 로컬 재생 파일로 내보내는 [경로](visual-action-collection.md#rerun-로컬-재생)가 있음. 실제 SDK·Viewer 연결은 미검증 | 두 영상·명령·관측 거절을 같은 근거와 시간축에서 검토 |
| W&B | 고정 모델·자료 분할·기준선 비교 기록을 연동할 수 있음 | 현재 실행 원본을 대체하지 않고 실험 버전·평가 비교에 사용. 외부 전송 범위는 별도로 정함 |
| Gazebo | 전체 팔 모델의 보정 후 검토 | ROS2 제어 흐름·접근 경로와 충돌 조건의 모의 실험 |
| MuJoCo | 전체 팔·구동·하중 모델의 보정 후 검토 | 접촉·마찰·하중 가설과 정책 비교. 실물 출력·접촉 차이를 검증하기 전 시뮬레이션 결과를 실물 성능으로 옮기지 않음 |

시각화와 실험 기록은 현재 원본으로 시작할 수 있지만, 시뮬레이터 완성을 첫 국소 집기의 선행 조건으로 삼지 않는다. Gazebo·MuJoCo를 사용하더라도 상태 관측과 실물 모델의 결손은 별도로 해결해야 한다.

## 기존 구현·실측을 찾아보는 곳

과거 M2의 수집 순서·시간창·분할·고정 출력, 원본 저장과 재생의 자세한 계약은 [시각 행동 수집기](visual-action-collection.md), [현장 감독 수집](supervised-action-collection.md), [유한 출력 프로파일](finite-output-profile.md), [무명령 관측 반복성](stationary-repeatability.md)에 유지한다. 날짜별 수치와 실패는 [실험 증거 색인](README.md#날짜별-실험-증거)에서 확인한다.

이 문서는 현재 설계와 남은 연결을 설명한다. 과거 실측 당시의 장치 상태나 실행 조건을 현재 전원·연결·촬영 상태로 재사용하지 않는다.
