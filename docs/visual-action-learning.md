# 영상과 명령으로 배우는 로봇 동작

[프로젝트](../README.md) · [연구 근거와 적용 판단](research/visual-action-learning.md) · [기존 행동 데이터 구현](data-pipeline.md)

MotionBrain의 목표는 로봇이 자신의 움직임을 관찰해 명령의 결과를 배우고, 그 예측으로 목표에 접근하는 것이다. 고정 외부 카메라 영상과 모터 명령·실행 기록을 연결해 자기지도 방식의 동작 모델을 만들고, 기구학과 기존 제어를 함께 활용한다. 사람이 모든 동작을 시연하는 모방학습 대신, 범위를 정한 행동을 실행하고 결과를 관찰하는 방식으로 시작한다.

**2026-10-31 상태:** 별도 M2 반복 수집과 원본 심사를 거쳐 첫 행동 예측 모델의 학습·평가를 완료했다. 투영 방향 전이 32개를 학습 16/검증 8/시험 8로 분리했고, 검증에서 선택한 선형 모델의 시험 평균 절대오차는 0.665°, 방향 일치는 8/8이다. 같은 날·같은 구도의 초기 결과이며 [오프라인 후보 선택](offline-action-selection.md)을 저장 모델에 연결했다. 이후 [첫 실물 목표 접근](evidence/2026-10-31-first-model-goal-approach.md)에서 모델 선택 M2 명령 1회로 영상상 목표 오차를 5.479°→0.967°로 줄였다. 반복 제어 성능은 미검증이다. [조건·분모·실패·한계](evidence/2026-10-31-first-action-prediction.md). 기존 M4·물체 박스 계약과 별개로 심사했으며, 정지사진 검출의 완성을 선행 조건으로 삼지 않는다.

## 첫 목표와 확장 방향

첫 실험은 같은 구도의 별도 논리 그룹을 보류해 짧은 명령의 결과를 예측했다. 모든 분할에 같은 8개 조건을 포함했으므로 학습에서 보지 않은 자세 범위나 다른 날짜의 일반화까지 검증한 것은 아니다. 저장 상태에서 후보 명령을 비교하는 오프라인 선택기를 연결했다. 관측→선택→단일 제한 실행을 실물 1회에서 측정했다. 현재는 이 첫 연결의 개념 검증을 마친 단계다. 다음 중심 과제는 현재 자세에서 이어지는 일괄 수집으로 경험을 늘리고, 묶음 단위로 후속 모델을 학습·평가하는 것이다. 실제 접촉·파지·옮기기 성공은 별도로 평가한다.

관절 각도 전체와 정확한 3D 모델을 먼저 복원할 필요는 없다. 집게 끝과 움직이는 링크의 여러 특징점으로 시작하고, 카메라에서 구별되는 자세·방향 범위를 실험으로 확인한다. 센서가 없는 M1·M2·M3·M5 중 관측이 명확한 축도 첫 대상이 될 수 있다. M4의 AS5600은 비교 근거로 활용하며 모든 실험의 필수 입력으로 강제하지 않는다.

```text
최근 팔 영상·명령 이력·사용 가능한 센서
                   + 후보 모터 명령
                            ↓
                다음 팔·집게 위치 변화 예측
                            ↓
                 목표와 후보 결과 비교
                            ↓
                제한된 명령 하나 실행
                            ↓
               출력 종료·영상 정착 확인
                            ↓
                새 관측과 결과를 기록
```

## 첫 성공 이후의 진행 계획

단일 목표 접근의 성공은 관찰·학습·선택·실행의 연결 근거다. 반복 성공률·연속 목표 접근·다른 조건의 일반화까지 검증한 것은 아니다. 좁은 시작 자세를 매번 맞추는 12회 비교안은 맞춤 동작의 왕복을 유발했고, 구간 확장안도 다음 실행안으로 채택하지 않았다. 관련 코드와 실패 기록은 보존한다.

이후 작업의 중심은 **연속 관측과 다양한 명령의 일괄 수집 → 사후 심사 → 묶음 학습 → 별도 평가 → 부족한 조건 보강**이다. 정밀 시작 자세 맞춤이나 하나의 성공 반복을 데이터 확대의 선행 조건으로 두지 않는다.

| 순서 | 할 일 | 완료 판단 |
| --- | --- | --- |
| 현재 | 첫 M2 예측 모델과 단일 실물 목표 접근 확보 | 기존 모델·분할·실측 결과를 재현 가능한 기준으로 고정 |
| 다음 수집 | 현재 관측 자세에서 허용된 후보를 연속 선택하고 모든 명령과 결과 기록 | 시도·유효/부적격·중단 수와 실제 조건 분포를 보존한 새 데이터 묶음 |
| 후속 학습 | 묶음 심사 뒤 선형·릿지부터 다시 학습, 필요하면 작은 신경망 비교 | 검증 묶음으로 선택하고 잠근 새 시험 묶음에서 오차·방향·실패 보고 |
| 실물 피드백 | 예측한 행동을 실행하고 결과를 재관찰해 다음 행동 선택 | 목표 오차 변화·실제 행동 수·보류/실패를 포함한 여러 단계의 기록 |
| 확장 | 부족한 자세·기간·출력과 다른 관절을 보강 | 조건별 성능과 일반화의 실제 근거; 이후 여러 축·접촉·파지 평가 |

### 수집: 자세를 맞추는 대신 현재 상태를 기록

명령 후보는 미리 정하고, 현재 관측과 구간별 수집량에 따라 실행 순서를 고른다. 움직인 뒤의 상태가 다음 사례의 시작 상태가 된다. 방향·기간 조합을 골고루 수집하되 시야나 운용 범위 때문에 실행할 수 없는 후보는 건너뛰고 부족량을 기록한다. 조건별 횟수를 억지로 채우려고 원래 자세로 왕복하지 않는다. 기존 예측기의 학습 입력 범위와 새 데이터를 수집할 실물 운용 범위는 구분한다.

초기 확대는 움직임이 확인된 M2와 기존 출력 수준에서 시작하고, 짧은 기간도 포함해 기존700/900ms 사이의 제한된 선택을 보완한다. 다음 묶음에서 출력 수준·자세·이력을 넓힌다. 현재 자세를 기준으로 선택한 모든 움직임은 수집 사례로 기록한다. 무변화·목표 초과 등 기대와 다른 결과도 관측과 명령 대응이 유효하면 학습자료다.

연속 수집은 촬영을 유지하며 여러 사례를 자동 진행한다는 뜻이다. 첫 모델의 +4초 정착 결과를 학습할 때는 그 결과 창이 끝나기 전에 다음 명령을 겹치지 않는다. 동작 중 궤적은 별도로 보존한다. 기존 맞춤 명령도 사후 심사할 수 있으나, 다음 명령이 정답 창을 침범한 자료를 독립된 +4초 전이로 승격하지 않는다.

실행 중에는 허용 명령·총량, 장치/출력 상태, 현재 관측의 사용 가능성과 운용 범위를 확인한다. 추적 완전 소실·통신 결과 불명·기계적 이상에는 정지한다. 학습용 결과 창의 품질 불합격은 해당 사례에 기록하며, 이후 현재 관측과 출력 상태가 다시 적격인 경우 남은 계획을 이어갈 수 있도록 실행 조건과 라벨 심사를 분리한다. 실패 명령을 자동 재전송하거나 추적 고장을 조용히 해제하지 않는다. 이 분리는 앞으로 구현할 계획이며 기존 실행기 동작을 문서만으로 바꾸지 않는다.

### 묶음 학습과 평가

촬영/연속 시퀀스 전체를 분할 단위로 삼는다. 서로 다른 명령 종류를 영상 하나씩에 몰아넣어 학습·검증·시험으로 나누거나 인접 프레임을 무작위 분할하지 않는다. 각 역할의 여러 시퀀스에 후보 명령을 배치하고, 실제 자세·방향·기간의 분포와 누락을 따로 보고한다. 같은 세션에서 얻은 성능과 다른 날짜·구도의 일반화는 구분한다.

새 묶음의 분할·입력/정답 정의·지표·선택 규칙을 학습 전에 고정한다. 기존32개와 모델은 기준 버전으로 보존하고 이미 살펴본 기존 시험8개를 새 독립 시험으로 재사용하지 않는다. 사후 실제 출력과 결과 영상은 정답 검증에 쓰며 사전 예측 입력으로 유출하지 않는다. 기존 모델과의 직접 비교는 공통 지원 범위에서 하고 새 명령 영역은 별도로 평가한다.

학습은 일괄 수집 후 묶음 단위로 한다. 무변화·속도 유지·명령 조건부 선형/릿지 기준선을 유지하고, 복잡한 모델은 같은 데이터에서 실제 개선이 있을 때 선택한다. 학습 적격 수, 전체 시도 대비 누락/실패, 예측 절대오차·큰 오차·방향 일치, 조건별 결과를 함께 보고한다. 정해진 횟수를 채우지 못했다는 이유만으로 유효한 묶음을 버리거나 자동 추가 구동을 하지 않는다. 사전에 정한 분할별 학습·평가 가능 조건을 만족하는지 심사한다.

### 저장과 구현 범위

현재1920×1080 BGRA 원본은 한 프레임8,294,400바이트다. 최대8fps로10분을 저장하면 영상 바이트만 약39.8GB다. 많은 사례를 모으는 계획에는 저장 예산을 함께 계산해야 한다. 기존 원본을 삭제하지 않고, 새 촬영을 위한 영상 파일·프레임PTS·명령/출력 기록의 연결 저장 또는 별도 저장공간을 검토한다. 새 영상 형식은 추적 재현과 시간 대응·종료 파일 완결성을 확인한 뒤 사용하며 아직 구현된 것으로 보지 않는다.

다음 구현 범위는 현재 상태에 따른 후보 배치, 일괄 기록, 사례별 사후 심사, 가변 크기 데이터셋과 묶음 학습·평가다. 기존32개/학습16개에 고정된 계약을 몰래 늘리지 않고 별도 버전으로 확장한다. 현재 단일 목표·12회 비교 실행기를 그대로 새 수집기에 사용하지 않는다.

## 구현 기반과 필요한 연결

| 구성 | 현재 기반 | 새로 필요한 부분 |
| --- | --- | --- |
| 모터 실행 | 제한 행동 실행기와 M2 양수 전용 프로필. `/actions`는 기본 비활성 | 별도 M2 양방향 반복 경로 실측 완료. 공개 단발 CLI와 구분해 재사용 연결 검토 |
| 실행 결과 | 명령/부팅 ID, 종료 이유, `driver_write`·OFF 이력과 원본 프레임 연결 | 새로운 실험에도 원본 심사와 오류 기록 유지 |
| 영상 | Mac 연속 BGRA·PTS와 고정 18점/6패치의 M2 상대 방향 관측 | 현재 구도 검증에 한정. 다른 구도·가림·다른 축의 표현 검토 |
| 학습 | 명령 조건부 선형·릿지, 무변화·속도유지 기준선의 첫 32개 학습·평가 완료 | 일괄 수집 데이터로 후속 학습, 새 보류 묶음과 조건별 평가 |
| 계획과 제어 | 기구학/ROS2 모델·기존 명령 경계·오프라인 후보 선택 | 단일 목표 접근 완료; 데이터 확대·후속 학습 뒤 다단계 피드백 평가 |

기존 [데이터 계약](data-pipeline.md)의 광학 영상 100ms·M4 20ms 등 조건은 해당 구현의 동작으로 유지한다. 새 접근은 **관측 → 제한된 실행 → 출력 종료 → 영상 정착 관측**에 맞는 별도 버전의 계약으로 설계한다. 문서 변경으로 기존 가드를 완화하거나 과거 부적격 자료를 적격으로 바꾸지 않는다. 새 계약의 시간·정착 기준은 실제 관측 잡음과 지연을 확인해 모델 평가 전에 고정한다. PTS·수신 시각은 광학 노출 시각과 구분한다.

## 입력과 학습 정답

| 구분 | 제안 내용 |
| --- | --- |
| 사전 입력 | 팔 특징점 위치·가시성, 최근 영상/명령 이력, 사용 가능한 M4 실측, 명령 종류·채널과 종류별 필드(non-M4: 방향을 포함한 PWM·요청 지속시간, M4: 목표각·출력 비율·시간 한도), 알려진 램프 설정 |
| 첫 정답 | 실행 후 정착 구간의 팔 특징점 변화. 프레임별 원본·추적 신뢰도와 연결 |
| 사후 근거 | 실제 드라이버 출력 이력, 실행시간·종료 이유, 출력 OFF, 영상 정착, 실패·불명 상태 |
| 이후 확장 | 동작 중 속도·이력 효과, 여러 축 조합, 목표 접근, 접촉·파지 결과 |

M4는 목표각 명령이고 다른 네 축은 PWM 펄스이므로 같은 물리량으로 취급하지 않는다. `src/motor/motor_driver.h`의 일반 램프 설정은 최소 갱신 간격 50ms·기본 변화량 10이다. 실제 갱신은 제어 루프의 `update()` 호출에 달려 있으며, 정지 근처의 0 처리와 즉시 정지는 별도 경로다. 실제 갱신 시각과 PWM은 출력 기록으로 확인한다. 요청 PWM이 실행 전체에 그대로 적용됐다고 가정하거나 `PWM × 시간`만으로 행동을 표현하지 않는다. 사후 실제 출력·실행시간을 사전 예측 입력으로 넣지 않는다.

영상 특징점은 팔의 관측 표현이며 정밀 관절각 정답은 아니다. 카메라가 움직이거나 점이 가려지면 해당 조건과 불확실성을 기록한다. 움직이지 않았다는 결과만으로 기계적 끝각도를 판정하지 않는다. 반대 방향의 동일 명령이 원점 복귀라는 가정도 두지 않는다.

## 단계와 판단 기준

| 단계 | 수행 내용 | 확인할 결과 |
| --- | --- | --- |
| 관측 파일럿 | 고정 구도에서 무출력 흔들림과 한 축의 움직임 비교 | 추적 오차와 구별되는 이동, 행동 전후 연결, 관측 누락률 |
| 동작 데이터 | 초기에는 PWM 수준 고정·지속시간 변화, 양방향과 여러 시작 자세. 이후 출력 수준 추가 | 같은 조건의 변동과 자세·이력에 따른 차이 |
| 결과 예측 | 무변화·국소 선형/릿지 기준선과 작은 신경망 비교 | 보류한 시작 자세·시퀀스에서 위치 변화 오차와 이동 방향 일치 |
| 목표 접근 | 후보 명령별 결과를 비교해 하나 실행하고 재관찰 | 목표 오차, 도달/실패/중단 분모, 기준 제어 대비 개선 |
| 경험 기반 개선 | 부족한 자세·방향 자료 보강, 이력 모델·앙상블·잔차 제어 검토 | 고정 비교 과제에서 개선 유지 여부. 이후 접촉·파지 과제로 확장 |

새 관절·관측 방법·PWM/시간·시도 수·총 시간은 해당 실행안에서 정한다. 범위를 확인하지 않은 최대 출력 탐색이나 정지점에 힘을 주는 방식으로 끝각도를 수집하지 않는다. 연속 관측이 가능한 유한 수집을 먼저 구성하며, 자율적인 수집·학습·재실행을 무제한으로 연결하지 않는다.

같은 반복·연속 영상·동작 시퀀스는 같은 분할 그룹에 둔다. 일부 시작 자세 또는 별도 세션을 평가용으로 보류하고, 학습에 사용한 자료의 재현 성능과 구분한다. 처리 실패·추적 실패·미평가를 보고하며 유리한 프레임만 선택하지 않는다. 관측 잡음과 파일럿 이동량으로 허용오차를 정한 뒤, 모델 결과를 보고 합격 기준을 바꾸지 않는다.

## 기구학과 학습의 역할

기구학은 링크·회전축·공간 관계의 사전 지식으로, 역기구학은 상태 추정이 충분해진 뒤 목표 자세의 후보를 구하는 데 사용한다. 학습 모델은 실제 출력·시간과 관측 이동의 관계, 마찰·유격·자세별 차이를 다룬다. URDF의 표시값과 제한값을 검증 없이 실물의 정확한 길이·끝각도·도달 범위로 사용하지 않는다.

처음에는 유한한 후보를 비교하는 한 단계 예측 제어로 시작한다. 이후 기존 제어의 오차를 학습하는 잔차 제어와 보상 기반 강화학습을 검토한다. 앙상블 모델의 불일치는 추가 관측할 조건을 찾는 신호이며, 안전 확률이나 물리적 보증값은 아니다.

## 인식·계측 자산의 위치

대상 물체·집게 검출기는 대상 위치와 결과 분석을 보조한다. 물체가 없는 팔 자체 동작 데이터도 수집할 수 있으므로 새 행동 파일럿을 위해 정지사진 검출의 모든 오류를 먼저 제거할 필요는 없다. 저장 영상 데모는 후속 표현 수단이며 행동 모델의 성과를 대신하지 않는다.

[Mac 카메라 계측](mac-direct-camera.md)은 영상 품질·시각 표식의 재사용 근거다. [OV2640 레지스터 진단](ov2640-register-diagnostic.md)은 기존 센서 전용의 보류된 경로이며, 외부 카메라 기반 행동 학습의 선행 단계가 아니다. 장치 전용 공간 추정 기능은 이 계획에 포함하지 않는다.
