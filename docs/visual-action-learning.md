# 영상과 명령으로 배우는 로봇 동작

[프로젝트](../README.md) · [연구 근거와 적용 판단](research/visual-action-learning.md) · [문서·실험 증거 색인](README.md)

MotionBrain의 목표는 로봇팔이 현재 영상과 예정 명령으로 움직임의 결과를 예측하고, 후보 결과를 비교해 물체에 접근·접촉·들기까지 이어가는 것이다. 수집용 사람이 정한 명령, 학습 모델의 선택, 출력 제한과 현장 확인을 구분한다. 모든 관절이나 동시 복합 동작의 학습을 첫 집기의 선행 조건으로 두지 않는다.

## 현재 단계 (2026-11-10 문서 정리 기준)

| 대상 | 확인한 범위 | 남은 경계 |
| --- | --- | --- |
| M1 닫기 | 턱축 간격 V1·V2의 고정 후 새 닫기 평가 각 1건 | 명령 평균 대비 개선 미입증. 턱축 간격은 실제 턱끝 전진·접촉 예측이 아님 |
| M2 손목 | 과거 고정 구도의 모델 선택 단일 목표 접근 | 반복 접근·새 구도·다른 관절 자세로의 전이는 미검증 |
| M3 팔꿈치·M4 어깨 | 팔 표식 기반 관측·학습과 별도 M4 센서 예측·상승 평가 경로 | 각 실험의 구도·방향·초기 자세·하중 범위에 한정 |
| M5 베이스 | 공통 단발 수집의 관절 선택 기반 | 선택 가능과 새 과제의 유효 데이터·고정 평가·제어 적격은 다름 |
| 닫기→들기 연결 | 고정 모델과 접촉 검토를 잇는 제한 코어 구현 | 별도 수동 닫기 6회·M4 상승 시험 3회에서는 최종 유지 들림 실패. 모델 선택 연결 성공이 아님 |

최신 M1 모델 비교와 수동 시험의 분모·실패는 [11월 9일 실측 기록](evidence/2026-11-09-shaft-evaluation-and-contact-probe.md)에 둔다. 과거 M2의 단일 목표 접근은 [별도 실측](evidence/2026-10-31-first-model-goal-approach.md), 팔 표식의 M3·M4 결과는 [해당 실험](evidence/2026-11-06-projected-arm-m3-m4-learning.md)을 따른다. 과거 650ms M4 모델의 선택 들림을 새 500ms 모델이나 전체 집기 성공으로 옮기지 않는다.

## 관측과 예측을 연결하는 구조

```text
현재 영상·사용 가능한 상태 + 예정 후보 명령
                    ↓
        후보별 다음 상태 예측과 정지 비교
                    ↓
       지원 범위 안의 명령 하나만 실행
                    ↓
     출력 OFF → 새 관측 → 실제 결과 평가
```

모델은 명령 뒤의 실제 상태를 예측한다. 예측한 다음 상태를 실제 관측처럼 사용해 다음 단계를 진행하지 않는다. 정지·보류가 선택되거나 관측이 불명확하면 원본과 이유를 남긴다.

| 자료 | 현재 역할 | 혼동하지 않을 것 |
| --- | --- | --- |
| 집게 위 영상 | 물체 기준점과 양턱의 상대 위치·턱점 거리를 측정 | 투영된 픽셀 간격은 물리 개구폭·깊이·접촉력이 아님 |
| 외부 카메라 | 팔·물체·탁자 관계, 팔 표식과 들림 결과 검토 | 박스 중심이나 한 장의 사진만으로 파지 깊이·공중 보유를 확정하지 않음 |
| 예정 명령 | 관절·방향·출력·요청 시간 또는 해당 실행기의 목표값 | 사후 출력 이력을 사전 입력으로 사용하지 않음 |
| 실제 출력·사후 영상·센서 | 실행 여부·정답·종료와 예측 오차의 근거 | 정상 명령 완료와 학습 제어 성공을 동일시하지 않음 |

M1에는 세 픽셀 상대 상태 모델과 별도 1차원 턱축 간격 모델이 있다. 짧은 M4 들기는 후보별 평균 변화를 사용하는 국소 전이 모델을 사용한다. 센서 변화량·물체와 턱의 상대 좌표·물체 없는 팔 표식은 각각 다른 관측 계약이다. 서로 다른 카메라·자세·하중·점 정의의 자료를 자동 혼합하지 않는다. [상대 상태 모델](relative-action-selection.md), [팔 표식 모델](projected-arm-learning.md), [수집 원본 계약](manual-data-collection.md)에서 각 경로를 설명한다.

등록한 특징 대응이나 원호 추출은 현재 구도용 관측 도구다. 관측 정확도·접촉 판별의 검증을 대신하지 않으며, 모호한 대응을 제외한 뒤 유리한 표본만 성과 분모에 남기지 않는다. [등록 특징과 원호 관측 계약](model-grasp-trial.md#등록-특징과-원호를-사용하는-새-관측-계약)을 모델 파일·입력 범위와 함께 고정한다.

## 전체 팔에서 기구학·동역학을 쓰는 방법

전체 팔의 URDF와 [정기구학·역기구학 계산](../ros2_ws/src/motionbrain_ros_bridge/motionbrain_ros_bridge/motionbrain_kinematics.py)은 구현돼 있다. 링크·축·좌표계의 모델을 계산하거나 표시하는 것과 실물의 끝단 위치를 정확히 아는 것은 다르다. M4 센서와 별개로 다른 관절의 실제 각도, 링크 치수·영점과 카메라 좌표계의 보정이 충분하지 않다. 미측정 관절을 0으로 채워 전체 팔 자세나 들림 높이의 실측값으로 사용하지 않는다.

정기구학·역기구학의 양의 pitch는 위쪽 상승각이다. 표시·mock·하드웨어 URDF의 팔 pitch축은 `−Y`로 통일하며, ROS `PoseStamped`의 회전은 상승각의 음수를 pitch로 사용한다. 고정 `tool0`는 손목 축에서 전체 0.11m 앞의 가상 도구 기준이고 집게 개방각과 독립적이다. 내부 몸체 원점까지 0.045m, 그 원점에서 `tool0`까지 0.065m로 배분하며 이 분할은 nominal이다. 집게 개방에 따라 움직이는 실제 손가락 끝과는 구분한다. 집게 턱과 카메라 형상은 개략 표시이며 접촉·개구폭·카메라 외부 보정을 뜻하지 않는다. XML 관절 변환과 FK 위치·방향, IK 목표를 교차 검증하지만 실물 치수·영점 정확도는 별도 미검증이다.

기구학은 우선 관절·공간 제약과 도달 가능 후보를 검토하는 데 결합한다. 실제 상태와 좌표계가 확인된 뒤 역기구학으로 접근 자세 후보를 만들고, 학습한 명령 반응으로 그 후보에 접근하는 구조로 확장한다. 두 카메라의 접촉·지지 검토와 기존 출력·각도 제한은 별도로 유지한다.

현재 동작 예측은 관측 상태와 명령 사이의 국소 관계다. 질량·관성·토크·마찰·접촉력을 식별한 전체 팔 동역학이나 역동역학 제어는 구현·검증하지 않았다. 실제 램프 출력, 직전 방향·정지 대기·자세·하중을 기록해 단순 기준선과 비교해야 한다. 움직임이 작았다는 사실만으로 마찰·유격·기계적 한계 중 하나를 원인으로 확정하지 않는다.

## 전체 관절의 수집·학습 계획

목표 단위는 **접근 → 정렬 → 닫기 → 들기·유지**다. M1만 보강하거나 모든 관절에 같은 횟수를 배정하지 않는다. M1~M5를 아래 표로 관리하고, 첫 과제에 필요한 관절부터 단일 관절 전이를 학습해 순차 연결한다. 처음부터 다섯 관절 동시 명령의 조합을 수집하지 않는다.

### 관절별 관측과 예측 대상

| 관절 | 과제에서의 역할 | 관측·예측할 변화 | 나눠 수집할 조건 |
| --- | --- | --- | --- |
| M5 베이스 | 물체 방향으로 접근·좌우 정렬 | 본체·팔 표식·물체와 턱의 영상상 상대 위치 변화 | 시작 회전의 관측 구간, 상완·전완 자세, 방향·예정 명령 |
| M4 어깨 | 높이·도달 위치 변경, 파지 후 상승 | 영상상 물체·턱 상대 변화와 센서 변화 | 시작 각도 구간, M3·M2 자세, 방향, 무부하·파지 조건 |
| M3 팔꿈치 | 도달 거리·높이 조절 | 팔 표식·손목·물체의 상대 위치 변화 | M4·M2 자세, 초기 팔꿈치의 관측 구간, 방향·하중 |
| M2 손목 | 접근 자세·접촉 높이 정렬 | 손목·양턱 끝·물체의 상대 위치와 방향 변화 | M4·M3 자세, 초기 손목의 관측 구간, 방향·하중 |
| M1 집게 | 접촉 위치를 보존하며 닫기·열기 | 실제 양턱 끝의 위치·간격·본체 기준 전진과 물체 이동 | 초기 개방 구간, 손목 자세, 물체 상대 배치, 비접촉·접촉 조건 |

센서 없는 관절의 초기 구간은 검증된 영상 관측으로 표현하고 미측정 각도를 만들지 않는다. 영상상 변화는 3차원 거리·접촉력과 구분한다. M1의 고정 `tool0`나 턱축 간격만으로 실제 손가락 끝 경로를 대신하지 않는다. 전후 프레임은 최종 변화를, 기존 외부 영상의 중간 프레임은 접촉 도중 밀림·궤적 검토에 쓴다. 두 카메라의 노출 동기화는 가정하지 않는다.

### 공통 실험 단위와 수집 순서

하나의 실험 단위는 **관절 × 관측 계약 × 초기 자세 구간 × 물체·하중 × 예정 명령**이다. 다른 관절 자세는 고정 조건으로 기록하고, 자세를 바꾸면 별도 조건으로 검토한다. 과거 자료는 원본 감사와 관측 계약 확인 후 재사용하며, 새 구도·물체 자료에 자동 합치지 않는다.

1. **기존 자료와 지원 범위 정리:** 각 관절의 원본·모델·고정 평가·관측 거절을 대응시킨다. 수집 화면 지원, 실제 실행, 학습 전이, 제어 적격을 구분한다. 필요한 방향이 현재 실행기에서 막혀 있으면 제한을 우회하지 않고 해당 경로를 별도 구현·검증한다.
2. **관측 고정:** 대비 좋은 무광 물체와 고정 외부 구도를 사용한다. 물체 교체·카메라 이동은 새 조건이다. 무명령 반복 관측으로 특징의 흔들림·가림을 확인하고, 관측 불확실성보다 작은 반응을 학습 성과로 해석하지 않는다.
3. **작은 연결 묶음:** 필요한 각 관절·관측 계약에서 우선 유효 전이 4~6건을 목표로 원본→관측→학습 연결을 확인한다. 이는 운영 확인용 제안 수량이며 학습 충분성이나 실물 실행 허용을 뜻하지 않는다. 실패·미시작·준비 동작은 별도 분모로 보존한다.
4. **조건별 확대:** 출발안은 방향·명령별 초기 상태 3구간 × 반복 3회다. 시간·출력·자세를 한꺼번에 바꾸지 않고 제한된 명령 집합에서 상태 의존성을 비교한다. 첫 묶음의 품질·편차에 따라 다음 수량과 조건을 정한다. 열기·되돌림도 실물 명령으로 별도 기록하고, 접촉과 비접촉 시험을 구분한다.
5. **고정 후 새 평가:** 관절·조건별 모델과 관측기를 고정한 뒤 별도 수집 묶음에서 명령별 3~5건을 시작 목표로 사전 예측을 남긴다. 같은 동작의 두 카메라·인접 프레임은 같은 분할에 둔다. 평가 자료를 학습에 편입하면 다음 버전에는 새 평가가 필요하다.

수량 충족만으로 다음 단계에 진입하지 않는다. 관측 불가·범위 밖·기준선 동률·회귀는 보고하고, 차이가 불명확하면 조건 보강 또는 단순 기준선 사용을 검토한다. 모든 관절·전체 자세 조합의 학습 완료를 첫 집기의 선행 조건으로 두지 않는다.

### 단계와 판단 기준

실행 전 입력은 해당 시점의 영상·사용 가능한 상태와 예정 명령이다. 실제 PWM·실제 기간·사후 영상·사후 센서는 정답·감사 근거로 분리한다. M4 센서 변화 정답을 영상 자체의 정확도 검증으로 해석하지 않는다. 기존 모델이 받지 않는 상태를 추가할 때는 관측·학습·범위 검사·사전 예측 연결을 함께 보강한다.

| 판단 단계 | 비교·측정할 것 | 다음 단계 조건 |
| --- | --- | --- |
| 관절별 예측 | 턱끝·물체·팔 표식의 변화 오차, 해당 센서 오차. 상태 모델·명령 평균·무변화를 같은 사례에서 비교 | 관측 오차와 거절률을 포함해 적용 범위가 명확하고 후보 비교 근거가 있음. 소수 표본의 개선을 일반화하지 않음 |
| 접근·정렬 | 필요한 M5·M4·M3·M2 후보와 정지 비교, 실행 후 새 영상의 목표 상대 오차 | 지원 범위 안에서 순차 접근. 다음 모델이 지원하지 않는 자세에서는 보류 |
| 닫기 | M1 후보별 턱끝 전진·간격·물체 이동 예측과 실제 결과 | 물체 중심이 턱 사이에 있다는 이유로 접촉을 확정하지 않음. 접촉·지지는 별도 검토 |
| 들기·유지 | 파지 조건에 맞는 M4 및 필요한 관절의 예측, 바닥 이격·동반 이동·유지 | 출력 정상 종료와 실제 보유를 구분. 무부하 모델을 파지 하중에 자동 적용하지 않음 |
| 전체 작업 반복 | 사전에 정한 시작 배치·목표·유지 조건에서 접근→닫기→들기 | 시도·성공·실패·중단·미시작·사람 개입을 단계별 및 전체 분모로 보고 |

성공 거리·유지 시간·관측 허용 오차는 과제와 측정 가능 범위를 정한 뒤 평가 전에 고정한다. 사람의 배치·준비 명령·수동 파지와 모델 선택을 분리한다. 예측 상태를 실제 관측처럼 다음 단계에 넘기지 않는다. 새 물체·날짜·자세의 일반화 평가는 같은 조건의 고정 후 평가와 별도로 진행한다.

기존 실행·재처리·모델 고정 경로와 추가 구현 경계는 [파이프라인 설명서](experiment-pipeline.md#전체-관절-계획과-구현-범위)를 따른다. 실제 수집 수량·출력·기간은 현재 현장 조건과 지원 방향을 확인한 뒤 별도 실행 계획에서 확정한다.

## 강화학습과 도구 도입의 위치

현재는 상태 변화의 지도학습과 고정 모델의 후보 비교를 하고 있다. 보상으로 정책을 최적화하는 강화학습이나 전문가 행동을 복제한 집기 정책은 아직 학습하지 않았다. 먼저 고정 평가와 제한된 모델 선택 제어의 기준 결과를 확보하고, 재설정·보상·관측 실패 처리와 반복 가능한 과제를 정한 뒤 잔차 제어·모방학습·강화학습을 비교한다. [연구 근거](research/visual-action-learning.md)의 방법을 현재 장치의 검증 성능으로 취급하지 않는다.

다음 도구는 M1·M4 각각이 아니라 전체 팔의 관측·실험·모델을 대상으로 한다.

| 도구 | 현재 기반과 가까운 도입 범위 | 후속 조건과 목적 |
| --- | --- | --- |
| RViz | 고정 `tool0`와 가상 관절 슬라이더의 로컬 화면 연결 | 실측·추정·미측정을 구분한 전체 팔 상태와 목표·도달 후보 표시. 표시값을 실측 자세로 바꾸지 않음 |
| Rerun | 새 고정 평가 어댑터에서 두 카메라 전후 영상·사전 예측·실측 오차의 실제 SDK·Viewer 연결 확인. 기존 단일 카메라 [내보내기](visual-action-collection.md#rerun-로컬-재생)와는 별도 | 두 영상·명령·관측 거절을 같은 근거와 시간축에서 검토 |
| W&B | 실제 SDK의 오프라인 지표·평가표 기록과 별도 웹 게시 경로 연결 | 현재 실행 원본을 대체하지 않고 실험 버전·평가 비교에 사용. 외부 전송 범위는 별도로 정함 |
| Gazebo | 동일 URDF 기반 개략 팔·바닥·시험 물체의 로컬 GUI 연결. 물리 모델은 미보정 | ROS2 제어 흐름·접근 경로와 충돌 조건의 모의 실험 |
| MuJoCo | 동일 URDF 기반 개략 팔·가상 위치 구동기·시험 물체의 네이티브 Viewer 연결. 물리 모델은 미보정 | 접촉·마찰·하중 가설과 정책 비교. 실물 출력·접촉 차이를 검증하기 전 시뮬레이션 결과를 실물 성능으로 옮기지 않음 |

[실행 방법과 실제 연결 범위](robot-visualization.md)를 따른다. 시각화와 실험 기록은 현재 원본으로 시작할 수 있지만, 시뮬레이터 완성을 첫 국소 집기의 선행 조건으로 삼지 않는다. Gazebo·MuJoCo를 사용하더라도 상태 관측과 실물 모델의 결손은 별도로 해결해야 한다.

## 기존 구현·실측을 찾아보는 곳

과거 M2의 수집 순서·시간창·분할·고정 출력, 원본 저장과 재생의 자세한 계약은 [시각 행동 수집기](visual-action-collection.md), [현장 감독 수집](supervised-action-collection.md), [유한 출력 프로파일](finite-output-profile.md), [무명령 관측 반복성](stationary-repeatability.md)에 유지한다. 날짜별 수치와 실패는 [실험 증거 색인](README.md#날짜별-실험-증거)에서 확인한다.

이 문서는 현재 설계와 남은 연결을 설명한다. 과거 실측 당시의 장치 상태나 실행 조건을 현재 전원·연결·촬영 상태로 재사용하지 않는다.
