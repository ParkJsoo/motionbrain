# 집게 위 영상의 상대 상태 학습과 첫 후속 평가

[상대 상태 학습·선택 계약](../relative-action-selection.md) · [현재 학습 단계](../visual-action-learning.md) · [수집 사용법](../manual-data-collection.md)

2026-11-04 같은 구도·책상에 지지된 원통 물체에서 **M1 열기·닫기 각 2건, 총 4건으로 상대 상태 모델을 학습**했다. 모델을 고정한 뒤 새 열기 1건을 재학습 없이 평가했다. 이 1건에서는 무변화 기준이 가장 잘 맞았다. 수동 주석으로 연결한 개발 실험이며 자동 인식·영상 기여·물리 정밀도·모델 제어·파지 성공을 입증하지 않는다.

## 관측과 학습

외부 카메라로 팔·물체의 전체 배치를 확인하고 원본 연속 영상을 저장했다. 외부 측면 영상에서는 양 턱이 겹쳐 보였지만 집게 위 ESP32-CAM에서는 물체 상단과 양 턱 끝을 구별할 수 있었다. 모델 입력과 정답의 상대 좌표는 집게 위 영상에서만 만들었으며 두 카메라 좌표를 합치지 않았다.

- 상태는 물체 상단 기준점−양 턱 중점의 x/y와 투영 턱점 거리다. 실제 거리·개구폭·깊이·접촉은 아니다.
- 입력 주석은 명령 전 한 프레임, 정답 주석은 OFF 후 별도 프레임에서 만들었다. 각 프레임의 대응점을 분석가가 수동 표시했다. 약 ±3px는 표시 수준의 근사 추정이며 측정 정확도나 예측 신뢰구간이 아니다.
- 명령은 M1 열기·닫기 **40%·250ms**였다. 실제 PWM·출력 기간은 별도 기록이며 입력에서 제외했다. 첫 닫기의 실제 PWM은 −10→−20→−30→−40→−30→−20→−10→0으로 요청 비율을 곧바로 유지한 출력이 아니다.
- 원본 명령·카메라 해시·수신/저장 시각·OFF·단일 명령 출력 이력을 재감사했다. 집게 위 카메라의 별도 시간창과 한 수집 세션 안의 비개입 조건은 [관측 계약](../relative-action-selection.md#집게-위-카메라-자료의-연결)에 따른다.
- 명령별 상태 ridge와 명령별 평균·무변화를 비교했다. 첫 네 건으로 학습한 모델과 학습 자료 해시를 고정했고 후속 자료를 학습에 섞지 않았다. 같은 날 순차 자세의 개발 평가이며 독립 일반화 시험은 아니다.

250ms 전이 대부분은 근사 주석 해상도에서 명료한 변화를 구별하기 어려웠다. 같은 주석 좌표가 나왔다고 실제 이동이 정확히 0이라고 판정하지 않는다.

## 시도·실패 분모

첫 묶음은 **8시도·5완료·3실패, 실제 동작 명령 6회**다. 완료 5건 중 4건을 학습, 이후 1건을 고정 모델 평가에 사용했다. 모든 동작은 데이터 수집용 수동 계획이며 **모델이 선택해 실행한 실물 명령은 0회**다.

| 구분 | 결과와 처리 |
| --- | --- |
| 명령 전 시작 실패 1건 | 출력 이력 GET 오류, 촬영·동작 0. 원본의 OFF 미확인 표시는 유지하고, 별도 GET에서 같은 부팅의 IDLE·출력 0·빈 큐 확인 후 복구 기록을 분리 |
| 250ms 완료 5건 | 닫기 2·열기 3. 원본·출력·전후 영상과 최종 OFF 감사 통과. 학습 4/후속 평가 1 |
| 별도 500ms 닫기 실패 1건 | 실제 명령·결과·OFF는 기록했으나 사후 감시의 출력 이력 GET 오류로 중단. 195프레임 보존, 학습·평가 제외 |
| 250ms 명령 전 감시 실패 1건 | 동작 0, 134프레임과 최종 OFF 확인 보존. 학습·평가 제외 |

실패한 명령을 자동 재전송하거나 같은 실험의 성공 기록으로 대체하지 않았다. 오류 원문에 `URLError` 내부 원인이 없어 연결 단계나 시간 초과 원인을 확정하지 못했다. 별도 GET 8회는 모두 응답했지만 이것이 수집 장애 해소의 근거는 아니다.

## 고정 후 새 1건 평가와 한계

후속 열기 1건은 학습 세션·실행·프레임과 겹치지 않았다. 정수 근사 주석에서 전후 상태가 같아 무변화 기준의 잔차가 0이었다. 상태 ridge와 명령 평균의 3상태 벡터 오차는 각각 약 0.319px·1.118px였다. **이는 약 ±3px 근사 표시보다 작은 주석상 계산값이며, 서브픽셀 측정 정확도나 모델의 물리 정확도가 아니다.** 1건·한 조건으로 모델 우열이나 영상 기여를 판단하지 않는다.

학습 후 마지막 주석 상태와 가상의 턱 간격 5px 감소 목표를 비교했을 때 모델은 정지·열기·닫기 중 닫기를 골랐다. 이 선택은 오프라인 계산이며 실제 출력하지 않았다. 가상 투영 간격 목표는 파지 목표나 접촉 판정이 아니다. 자동 상태 추정과 여러 단계 모델 제어는 남아 있다.

## 신호 확인과 다음 자료

250ms의 변화가 작아 다음 별도 묶음에서 40%·350ms 닫기 **1시도**를 계획했지만, 명령 전 감시 실패로 **동작 0·완료 0**, 최종 OFF 확인 상태에서 종료했다. 첫 8시도 분모에 섞지 않으며 정답 영상을 만들거나 학습에 넣지 않았다. 350ms의 실제 반응은 이 시도로 확인하지 못했다.

다음 자료는 단순히 같은 횟수를 채우는 것보다 주석 오차보다 분명한 변화를 관측할 수 있는 명령·상태가 필요하다. 정렬용 M5 좌/우, 필요한 접근 방향, M1 닫기의 초기 턱 간격·물체 위치를 고정 구도에서 연결해야 한다. 현재 M1 자료를 다른 관절이나 접촉·들기 모델로 자동 확장하지 않는다. M4 위 방향 제한은 유지하며 허용 관절의 들기 경로·파지 유지 관측은 별도로 검증해야 한다.
