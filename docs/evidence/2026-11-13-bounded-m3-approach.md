# M3 개발 관측 모델의 첫 실물 접근

2026-11-13, 같은 물체·고정 구도에서 **고정한 새 모델이 선택한 UP 1회 후 새 영상이 목표의 좌표별 허용범위에 들어왔다.** 수동 복귀는 별도 1회다. 여러 번 보정하는 반복성, 접촉·집기·들기는 검증하지 않았다.

## 조건과 판정

집게 영상은 320×240, 외부 영상은 1920×1080이다. M4를 기준 196.17°의 ±0.5° 안에 고정하고 M3만 움직였다. 요청은 UP 60%·350ms이며, 실제 출력·램프·OFF는 드라이버 이력으로 확인했다. 요청 비율·기간을 그대로 실제 PWM·출력 시간으로 간주하지 않는다.

상태는 `[물체 중심−보이는 양턱 중점의 X, Y, 양턱 모서리의 수평 간격]`이며 단위는 px다. 목표는 수동 닫기 준비 기준 `[1,16.5,124]`, 좌표별 허용오차는 `[1.5,1.5,1]`로 시험 전에 고정했다. 이 영상 특징은 깊이·접촉·파지 정확도를 보증하지 않는다.

| 항목 | 상태 |
| --- | --- |
| 모델 시험 시작 | `[1,21,124]` |
| 선택한 UP의 예측 | `[-0.518,17.778,124]` |
| OFF 후 새 영상 실측 | `[-0.5,18,124]` |
| 목표와의 벡터 거리 | `4.500 → 2.121px` |
| 예측과 실측의 벡터 차이 | `0.223px` |

X와 Y 모두 허용오차의 **경계**에 도달했다. 벡터 거리와 좌표별 허용오차 판정을 혼동하지 않는다. 모델은 UP의 예상 거리 1.984px와 정지의 4.500px를 비교했다. DOWN은 학습 지원 범위 밖으로 거절됐으므로 양방향 제어 성능을 입증한 결과가 아니다.

동작마다 OFF와 새 관측을 요구하는 기존 반복 코어를 사용했다. 이번 시험은 명령 1회에서 끝났으며 다회 보정 실물 검증으로 세지 않는다. 사후 프레임은 OFF+3초 이후이고 학습 프레임과 중복되지 않았다. 카메라 간 노출 동기화는 검증하지 않았다.

## 자료·수동 준비·시험의 분모

| 구분 | 분모와 결과 |
| --- | --- |
| 현재 구도 개발 수집 | 5명령·5유효 전이: UP 3, DOWN 2 |
| 별도 수동 시작 배치 | DOWN 1명령 후 Y=24로 기존 상한 22 초과, 실패·중단 |
| 별도 수동 UP 복귀 | 1명령 후 원래 범위 복귀, 모델 성과에서 제외 |
| 첫 고정 모델 접근 시험 | 1시험·0명령: 시작부터 목표 안, 모델 접근 성공에서 제외 |
| V2 고정 후 접근 시험 | 1시험·모델 명령 1회: 좌표별 허용범위 관측 도달 |

수집 5건과 유효한 새 UP 복귀 1건만으로 **V2 6건(UP 4, DOWN 2)**을 학습했다. 실패한 DOWN을 자동으로 학습 자료에 넣지 않았다. 모델은 새 시험 전에 고정했고 시험 중 재학습하지 않았다. V2의 SHA-256은 `48a81a299085c9d37900da5ccb3ec27201302736b5b265334ee3ff9ca29ddb30`이다.

수동 시작 배치의 실패는 이미 보유한 DOWN 변화 최대 6px가 당시 남은 여유 4.5px보다 컸는데도 실행 전 거절하지 못한 계획 결함이다. 이후 원학습 행 해시와 경험적 도착 범위를 검사하는 사전 평가를 추가했다. 경험적 범위는 미래 결과의 보장 범위나 신뢰구간이 아니다.

범위 밖 수동 복귀에는 별도 단방향 계약을 사용했다. 첫 입력에만 좁은 집게 영상 범위와 외부 전완 반경 11px를 허용하고, UP 후에는 원래 집게 영상 범위·외부 반경 10px로 복귀해야 했다. 원래 접근 guard·목표·허용오차는 바꾸지 않았다. 실패·불명확 명령은 재전송하지 않았고 최종 다섯 모터 OFF를 확인했다.

## 해석의 한계와 다음 단계

모델 선택 실물 이동 1회가 확인된 조건부 결과다. 반복 성공률, 새로운 물체·구도에 대한 일반화, 독립된 대규모 예측 평가, 닫기·접촉·집기·들기는 미검증이다. 모델과 관측기의 `controlEligible=false`를 유지하고 별도 실험 계약으로만 연결했다.

[이전 M3 고정 평가](2026-11-12-m3-goal-prediction.md)의 모델과 **15/16 미통과**는 그대로 보존한다. 이번 새 구도·새 모델의 접근 결과를 이전 평가의 남은 한 건이나 통과 판정으로 대체하지 않는다. 다음은 현재 구도에서 필요한 M1 닫기 관측·모델 연결이다.
