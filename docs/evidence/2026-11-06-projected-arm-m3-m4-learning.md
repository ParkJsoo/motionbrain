# M3·M4 외부 영상 표식 학습과 고정 후 평가

[표식 상태 학습 방법](../projected-arm-learning.md) · [앞선 관절별 상대 상태 평가](2026-11-05-multi-joint-relative-learning.md)

2026-11-06 외부 카메라에서 같은 전완 링크의 두 녹색 표식과 고정 배경점을 주석해 M3·M4를 각각 학습했다. M3는 9건, M4는 4건을 학습 자료로 사용했다. 모델을 고정한 뒤 새 전이를 각각 2건·1건 확보했으나, M3는 관측 품질 기준에서 모두 거절됐고 M4는 학습 상태 범위 밖이라 예측을 거절했다. **후속 자료에서 정식 예측 오차를 계산할 수 있는 사례는 0건**이다. 학습 수행과 예측 성능 입증을 구분한다.

## 관측과 학습

- 외부 카메라의 1920×1080·4fps 원본에서 명령 전 저장된 입력과 출력 OFF 후 관측창의 정답 프레임을 기존 감사기로 선택했다. 집게 위 카메라 영상도 실행 전후 확인에 사용했지만 두 카메라의 픽셀 좌표를 혼합하지 않았다.
- 상태는 원위 표식−배경점의 x/y와 근위 표식−원위 표식의 x/y, 총 네 픽셀 값이다. 보정된 관절각·공구의 3차원 위치·물체와의 거리·접촉 상태가 아니다.
- 각 감사 프레임의 색 영역 중심 제안을 실제 원본과 함께 확인하고 정수 좌표로 주석했다. 프레임·픽셀·원본 해시와 명령 전/정지 후 시점 근거를 보존했다.
- 관절별·명령 조건별 ridge 모델을 분리했다. 같은 명령 전이가 2건 미만이면 해당 조건을 지원하지 않는다. 정답 영상·실제 출력·사후 센서는 사전 입력으로 사용하지 않았다.
- 고정 후 평가에서는 모델을 다시 학습하지 않았다. 배경 일치 품질과 학습 상태 범위 검사를 통과한 예측에 대해서만 명령별 평균·무변화 기준과 비교하도록 했다.

## 수집 분모와 지원 조건

아래 수치는 이번 재개의 M3·M4 자료이며 앞선 날짜의 자료나 M2 자료를 합산하지 않았다. 모든 실제 동작은 수집용 수동 계획이다.

| 관절 | 시도 | 완료·원본 적격 | 구동 전 실패 | 학습 자료 | 고정 후 새 평가 자료 |

| M3 팔꿈치 | 13 | 11 | 2 | 9 | 2 |
| M4 어깨 | 6 | 5 | 1 | 4 | 1 |

M3 학습 자료는 위·아래 40%·350ms 각 1건, 위 40%·500ms 4건, 아래 40%·500ms 3건이다. 500ms의 7건에 해당하는 두 명령 조건만 지원하며, 350ms 두 조건은 반복 수가 부족하다. 같은 9개 원본으로 물체·턱점 표현과 외부 팔 표식 표현을 별도 학습했으며 이를 독립 자료 18건으로 세지 않는다.

M4 학습 자료는 아래 20%·350ms 3건과 아래 20%·500ms 1건이다. 350ms만 지원한다. 고정 후 평가 동작도 아래 20%·350ms 1건이다. 이번 M4 자료를 과거 센서 정답 기반 학습 18건·평가 18건과 혼합하지 않는다.

## M3: 관측 품질 거절

학습 때는 대상 물체가 있었고 후속 2건은 물체 없는 장면이었다. 팔 표식 상태에 물체 위치를 입력하지 않더라도 이 장면 변화는 별도 조건 변화로 기록했다.

고정한 배경점 이동 허용치는 2px였다. 후속 위·아래 40%·500ms 두 전이 모두 배경 이동이 약 2.236px로 검출되어 이 기준을 넘었다. 원본 감사는 통과했지만 관측 품질 부적격으로 정식 예측 평가에서 거절했다. 결과를 본 뒤 임계값을 넓히거나 주석으로 덮어쓰지 않았다.

따라서 원본 적격 2건·관측 품질 거절 2건·정식 평가 0건이다. 별도 수치 재생 진단은 정식 예측 성능으로 계산하지 않는다.

## M4: 학습 상태 범위 거절

M4는 학습과 후속 평가 모두 물체 없는 조건이었다. 첫 M4 학습 입력만으로 배경 참조를 만들고, 이 관절의 배경 이동 허용치를 수집 전에 3px로 정했다. M3의 고정 기준을 소급 변경한 것이 아니다.

후속 1건은 배경 이동 약 1.414px·일치 점수 약 0.996/0.997로 관측 품질을 통과했다. 그러나 명령 전 네 상태 값이 학습 입력 범위 검사에서 거절되어 예측을 내지 않았다. 원본 적격 1건·관측 적격 1건·범위 거절 1건·정식 평가 0건이다.

## 해석과 남은 검증

이번 자료로 실제 수집→원본 감사→표식 주석→학습→모델 고정→새 자료 평가의 경로를 실행했다. 다만 두 관절 모두 후속 자료에서 정식 예측 성능을 얻지 못했으므로 영상 상태의 이득이나 제어 정확도를 주장하지 않는다.

같은 날의 좁은 순차 자세 자료이며, 다른 관절의 자세·중력·하중·마찰·유격·관성·직전 방향의 영향을 인과적으로 구분한 실험이 아니다. 실제 출력과 요청 기간도 별도 근거로 취급한다. 모델이 선택한 실물 명령은 이번 묶음에서 0회이며, 반복 목표 접근·학습 기반 집기·들기는 미검증이다.

후속 과제는 관측 품질을 유지하는 조건에서 시작 자세 범위를 넓히고, 충분한 반복으로 학습한 뒤 별도 고정 평가를 수행하는 것이다. 새 관절이나 다른 몸체에 붙인 표식은 별도 관측 계약으로 수집·학습하며 이 좌표와 자동 혼합하지 않는다.
