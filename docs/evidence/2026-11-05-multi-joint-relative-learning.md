# 관절별 상대 상태 자료 확대와 고정 모델 평가

[상대 상태 계약](../relative-action-selection.md) · [현재 학습 단계](../visual-action-learning.md) · [수집 안내](../manual-data-collection.md)

2026-11-05 제한된 구도에서 M1·M5·M2의 새 전이 **33건**을 확보했다. 관절별 **8건씩 총 24건으로 각각 학습**하고 모델을 고정한 뒤 **9건을 후속 수집·평가**했다. 모델 선택 실물 명령·집기·들기는 수행하지 않았다. 모든 동작은 자료 수집용 수동 계획의 한 관절 단발이다.

## 목표와 실제 분모

수집 목표는 M5 12·M1 12·M2 12·M3 8·M4 아래 6, 합계 50건이었다. 목표량과 실제 확보량은 다르다. 이전 중단 묶음의 5시도·동작 0건을 그대로 보존했고, 이번에는 **40시도 중 33완료·7실패**, 누적 시도는 45회다. 새 실패 7건에는 실제 구동이 없었다. 완료 33건은 서로 다른 원본 세션이며 단일 명령·실제 출력·최종 정지와 영상 계약을 재감사했다.

| 관절 | 이번 시도 | 완료·원본 적격 | 학습 | 고정 후 평가 자료 | 예측 가능 / 범위 거절 |
| --- | ---: | ---: | ---: | ---: | ---: |
| M1 집게 | 14 | 12 | 8 | 4 | 3 / 1 |
| M5 베이스 | 13 | 12 | 8 | 4 | 1 / 3 |
| M2 손목 | 12 | 9 | 8 | 1 | 0 / 1 |
| M3 팔꿈치 | 1 | 0 | 0 | 0 | 해당 없음 |
| M4 어깨 | 0 | 0 | 0 | 0 | 미시작 |
| 합계 | 40 | 33 | 24 | 9 | 4 / 5 |

실패는 사전 영상 검토·여유 확인에서 중단 4건, 명령 설정 단계의 인증 거절 1건, 호스트의 로컬 서버 접근 거절 1건, M3 시작 전 출력 이력 조회 오류 1건이다. 실패·미시작을 완료로 대체하지 않았다. M3는 촬영·구동 모두 시작되지 않았고, M4는 공통 경로 중단으로 시도하지 않았다. 종료 시 현재 출력 정지·같은 부팅의 출력 이력 무변경·빈 큐를 별도 조회로 확인하고 수집 서버를 종료했다. 실패 원본의 미확인 표시는 사후 확인으로 덮어쓰지 않았다.

## 관측·학습 조건

- 외부 카메라는 1920×1080·선택 기록률 4fps의 무손실 연속 영상으로 팔 전체·물체·간섭을 확인했다. 집게 위 ESP32-CAM의 320×240 전후 사진에서 물체 상단 중심과 양턱 끝을 각각 수동 표시했다. 두 카메라 픽셀을 혼합하지 않았다.
- 상태는 물체 기준점−턱 중점의 x/y와 투영 턱점 거리다. 실제 거리·관절각·물리 개구폭·깊이·접촉이 아니다. 약 ±3px는 점 표시의 근사 허용량이며 측정 정확도나 통계 신뢰구간이 아니다.
- 입력은 명령 전 한 프레임의 주석과 예정 명령이다. 출력·센서·명령 후 영상은 사후 검증과 정답으로 분리했다. 명령 전 저장·OFF 후 관측창, 원본 해시와 카메라 부팅·시점 계약을 재감사했다.
- 관절별 자세·물체·카메라 계약을 분리하고 기존 날짜의 학습 자료를 합치지 않았다. 학습 모델·학습 명세·코드 해시를 고정했으며 새 평가 정답으로 재학습하지 않았다. 범위 밖 상태는 외삽하지 않았다.

| 관절 | 학습 조건과 표본 |
| --- | --- |
| M1 | 닫기 40%·350ms 4건, 열기 40%·350ms 2건, 열기 40%·500ms 2건. 닫기 500ms는 사전 검토에서 중단돼 모델 지원 조건이 아님 |
| M5 | 왼쪽 40%·500ms 3건, 오른쪽 50%·500ms 2건을 모델이 지원. 왼쪽·오른쪽 40%·350ms 및 오른쪽 40%·500ms는 각 1건만 있어 지원하지 않음. 오른쪽 40%의 변화가 불명료해 별도 50% 조건을 추가 |
| M2 | 위·아래 63% × 550/700ms 네 조건을 각 2건씩 학습. 후속 550ms 두 건과 아래 700ms 한 건은 미구동 실패, 위 700ms 한 건만 평가 자료로 확보 |

요청 비율·기간은 예정 명령 조건이다. 실제 출력은 가감속과 정지 처리를 포함한 별도 기록이며 일정 PWM을 요청 시간 내내 유지한 것으로 간주하지 않는다. M4 위 방향 제한은 변경하지 않았다.

## 고정 후 평가

아래 수치는 **예측 가능한 동일 평가 부분집합**에서 3상태 벡터 오차의 유클리드 거리 평균이다. 거절된 자료를 작은 오차로 계산하거나 제외 사실을 숨기지 않는다.

| 관절 | 평가 자료 / 예측 / 거절 | 상태+명령 ridge | 명령별 평균 | 무변화 |
| --- | --- | ---: | ---: | ---: |
| M1 | 4 / 3 / 1 | 2.630px | 2.951px | 13.196px |
| M5 | 4 / 1 / 3 | 32.027px | 30.333px | 33.000px |
| M2 | 1 / 0 / 1 | 계산 불가 | 계산 불가 | 동일 비교 부분집합 없음 |

M1의 예측 가능 3건에서는 두 학습 방식이 무변화보다 오차가 작았지만, ridge와 명령 평균의 차이는 근사 주석 수준보다 작다. 영상 상태의 추가 이득이나 물리 정밀도를 입증하지 않는다. M5는 4건 중 3건을 거절했고 남은 1건도 오차가 커 예측 성능이 부족하다. M2도 학습 범위가 좁아 후속 자료에서 예측을 내지 못했다.

**원본 적격 33건은 명료한 움직임 33건을 뜻하지 않는다.** M5에는 주석상 0~3px 변화인 전이가 여럿 있으며, 일부 M1·M2 변화도 근사 주석 오차와 가깝다. 반대로 명확히 변한 상태에서도 M5 예측이 크게 빗나간 사례를 보존했다. 같은 좌표 표시는 실제 이동이 정확히 0이라는 보증이 아니다.

## 남은 범위

이번 묶음은 같은 날의 좁은 순차 자세에서 수행한 개발 실험이다. 다른 날·하중·구도 일반화, 자동 상태 추정과 학습 정책의 연속 제어는 미검증이다. 과거 [M1 4건 학습·1건 평가](2026-11-04-gripper-relative-learning.md)와 별도 조건이며 그 결과를 소급 변경하지 않는다.

공통 수집 경로의 출력 이력 초기 조회에서 시간 초과와 상태 조회 오류가 발생해 확대를 중단했다. 다음 실물 수집 전 이 경로와 현재 연결·영상·이동 여유를 다시 확인해야 한다. 이후 필요한 것은 관절별 상태 범위 확대와 반복 가능한 반응, 관측 오차 관리이며, 부족한 조건을 단순 반복해 목표 수량만 맞추는 것은 아니다. 모델 선택 실물 실행과 집기·들기는 별도 검증으로 남아 있다.
