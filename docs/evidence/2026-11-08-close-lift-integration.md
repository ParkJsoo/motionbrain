# 2026-11-08 닫기→들기 연결: M1 관측·입력 범위에서의 중단

[현재 학습 설계](../visual-action-learning.md) · [닫기→들기 코어](../model-grasp-trial.md) · [M4 위 방향 실측](../m4-up-commissioning.md)

현재 자세에서 M1 모델이 닫기를 선택하고, 새 접촉 확인 뒤 고정 M4 모델이 들기를 선택하도록 연결하는 실험이다. **이번 묶음은 M1의 관측·입력 범위에서 중단했으며, 고정 후 평가·모델 선택 닫기·연결 들기 실물 실행은 모두 0회다.** 정상적으로 종료한 준비 명령을 집기 성공으로 세지 않는다.

## 조건과 분모

고정된 집게 위 카메라의 320×240 영상에서 원통형 물체와 양턱의 상대 상태를 측정했다. 외부 카메라로 팔·물체·탁자를 함께 검토했고, 다른 관절은 고정한 채 M1만 수동 계획 명령으로 구동했다. 픽셀 상태는 물리 개구폭·깊이·접촉력의 정답이 아니다.

| 구분 | 수와 상태 |
| --- | --- |
| 실물 명령 | 총 7회: 수집 4회, 준비 열기 3회 |
| 수집 명령 | 열기→열기→닫기→닫기, 각각 40%·요청 350ms |
| 현재 계약에서 학습한 전이 | 4건, 열기 2·닫기 2. 이전 자세의 M1 자료는 혼합하지 않음 |
| 준비 명령 | 열기 40%·요청 350ms 2회와 200ms 1회. 학습·평가·모델 선택 성과로 세지 않음 |
| 고정 후 새 평가 | 0건 |
| 이 M1 모델이 선택한 닫기 | 0회 |
| 닫기→들기 연결 실물 실행 | 0회 |

각 명령은 출력 종료를 확인했다. 다만 원래 세 번째 명령은 사후 특징 추출 실패로 실패를 남겼고, 마지막 준비 명령도 사후 대응점이 모호해 실패로 남겼다. 출력이 정상 종료됐다는 사실과 학습·평가 자료의 적격 여부를 구분한다.

## 물체 관측을 바꾼 이유와 원래 실패의 보존

초기 등록 방식은 분석가가 지정한 물체 기준점과 양턱 패치의 이동을 정규화 상관계수(NCC)로 대응했다. 세 번째 수집의 물체 패치는 NCC 약 0.832로 고정 기준 0.85에 못 미쳤다. 명령·출력·영상의 원본 감사는 통과했지만 당시 특징 관측은 실패였다.

이후 중앙의 위·아래 원호로 원 중심 이동을 측정하는 별도 등록 계약을 만들었다. 분석가 기준점에 원호 중심의 상대 이동을 더하며, 양턱의 패치 대응은 그대로 품질 검사를 거친다. 원호 추출은 현재 원통·구도용 방법으로, 절대 중심의 정밀 보정이나 일반 물체 검출 성능을 뜻하지 않는다.

먼저 확보한 세 전이는 원본부터 새 계약에서 명시적으로 다시 감사했고, 새 닫기 전이 1건을 더해 총 4건으로 모델을 학습·고정했다. **새 계약에서 특징을 사용할 수 있다는 결과가 원래 세 번째 실패를 성공으로 바꾼 것은 아니다.** 원래 결과·원본·이전 관측 계약은 보존했다. 이후 준비 명령이나 거절된 측정으로 모델을 다시 학습하지 않았다.

## 준비 열기와 마지막 관측 거절

고정 후 준비 열기의 입력은 닫기 모델이 지원한 범위에 들어오지 못했다. 200ms 준비 명령 뒤에도 채택된 턱점 거리는 약 73.9px였고, 닫기 학습 입력의 범위 77.11~85.30px보다 작았다. 상대 y도 학습 범위 밖이었다. 이 명령에서 뚜렷한 개방 증가를 확인하지 못했으며 평가 명령을 보내지 않았다.

마지막 350ms 준비 명령은 정상 출력 종료 뒤 사후 오른쪽 턱의 대응 유일성 검사에서 거절됐다.

| 마지막 사후 오른쪽 턱 대응 | 값 |
| --- | ---: |
| 최고 후보 NCC | 약 0.98112 |
| 다른 후보 NCC | 약 0.94163 |
| 후보 점수 차이 | 약 0.03949 |
| 고정한 최소 차이 | 0.04 |

최고 NCC가 높아도 두 후보를 충분히 구별하지 못하면 채택하지 않는다. 기준을 낮추거나 다른 후보를 골라 평가를 강제하지 않았다. 거절된 최고 후보로 임시 계산한 턱점 거리는 약 87.7px였지만 **채택된 관측이 아니며**, 그 임시 값도 기존 닫기 학습 입력 범위를 넘었다. 이 값을 목표 개방폭이나 제어 입력으로 사용하지 않는다.

200ms와 마지막 350ms 명령은 모두 40% 요청이었지만, 실제 램프 출력 기록의 최대 PWM은 각각 40과 70이었다(0~255 척도). 요청 출력·기간이 실제 출력 이력과 같지 않음을 확인한 근거다. 이것만으로 반응 차이의 원인을 마찰·유격·힘 부족 중 하나로 확정할 수 없다.

## M4와 전체 팔 연결의 남은 조건

새 500ms M4 모델은 별도의 같은 구도·사람 사전 파지 조건에서 학습 4건과 고정 후 평가 2건을 확보했다. 상승량 예측 MAE는 2px로 명령 평균 기준 2px와 동률이며 무변화 기준은 11px였다. 이 모델의 선택 실행은 아직 0회다. 과거 650ms 모델의 들림 관측과 실행 실패는 [별도 기록](../m4-up-commissioning.md#2026-11-07-고정-모델-선택-들림과-실패-구분)을 따른다.

이번 준비 자세의 별도 M4 입력 진단에서는 집게 표식 상승 상태 약 −7.03px가 기존 ±6px 범위 밖이었다. 닫기 이후 상태가 달라질 수 있으므로 실제 닫기 뒤 새 두 카메라 입력과 각도 여유를 다시 확인해야 한다. M1 문제를 해결했다고 M4 조건까지 충족했다고 간주하지 않는다.

현재 결손은 더 많은 준비 열기 명령 자체가 아니라, 현재 자세를 신뢰할 수 있게 관측하고 닫기 모델의 적용 범위에 연결하는 방법이다. 그 조건을 확보한 뒤 새 고정 평가, 모델 선택 닫기, 실제 접촉·탁자 지지 확인과 M4 선택 들기를 구분해 평가해야 한다. 다른 관절의 정렬·접근이 필요해지면 전체 팔 기준으로 필요한 관절만 순차 확장한다.

마지막 출력 OFF·빈 큐 확인은 기록 당시 상태다. 이번 기록은 현재 장치 상태, 반복 성공률, 일반화, 자율 파지·들기 성공을 입증하지 않는다. 원본 이미지·응답·인증정보와 개별 실행 이력은 비공개로 보존한다.
