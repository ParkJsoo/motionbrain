# 립밤·집게 인식 개발 학습 결과

[동작 학습 방향](../visual-action-learning.md) · [CV 학습 실행기](../bounded-cv-training.md) · [저장 모델 평가](../checkpoint-evaluation.md)

2026-10-30까지의 인식 개발 실험 요약이다. 고정 외부 iPhone 사진에서 립밤과 집게를 검출하고 영상상 상대 위치·방향을 계산했다. **현재 모델의 최종 결과는 학습에 쓴 12장에 대한 적합성 확인이며 일반화 성능이나 로봇 행동 학습 결과가 아니다.**

## 자료와 기준

- 서로 다른 촬영 세션의 기존 6장과 새 6장, 원본 1920×1080. 각 세션은 립밤 존재 4장·부재 2장, 집게 존재 6장이다.
- 최종 학습 자료는 12장·상자 20개다. 집게는 가시 손가락/접촉부 범위를 사용하며 관절·모터 몸체와 가려진 외형을 포함해 복원하지 않았다.
- 기존 라벨에는 사람 입력과 검토 보완 이력이 있고, 새 세션의 상자 10개·립밤 부재 2건은 보조자가 제안한 라벨을 사람이 검토·확정했다. 독립 평가자 간 정확도 검증은 아니다.
- 모델은 Faster R-CNN MobileNetV3 320. 점수 0.5·NMS 0.5·정답 매칭 IoU 0.5, 상대 위치 허용오차 10px·방향 중립대 ±10px(960×540 기준)을 유지했다.

## 별도 세션 평가와 이후 학습을 구분한 결과

| 시점·모델 | 자료 | 립밤 TP / FP / FN | 집게 TP / FP / FN | 상대쌍·위치·방향 성공 |
| --- | --- | --- | --- | --- |
| 기존 모델의 새 세션 평가 | 당시 미학습 6장, 1회 | 0 / 1 / 4 | 0 / 0 / 6 | 각각 0/4 |
| 혼합 추가 학습 후 최종 모델 | 학습에 쓴 기존+새 12장 | 8 / 1 / 0 | 12 / 0 / 0 | 각각 8/8 |

두 경우 모두 처리 실패는 0건이다. 기존 모델의 새 세션 평가에서 립밤 부재 오탐은 0/2, 최종 모델의 학습 자료에서는 0/4였다. 새 6장을 추가 학습에 사용한 이후에는 최종 모델의 미학습 평가자료로 취급하지 않는다. 추가 학습 후 독립적인 새 사진 평가는 수행하지 않았다.

혼합 학습은 부모 checkpoint를 복원해 1회·300업데이트 수행했다. backbone을 동결하고 RPN·ROI 검출부를 학습했으며, optimizer는 새로 시작했다. 누적 인식 개발 학습은 4회·460업데이트다. 최종 저장 상태와 300회 평가 상태의 일치, 부모 checkpoint와 원본 보존을 확인했다. 오탐 0 목표는 달성하지 못했다.

## 남은 중복 검출

새 세션 첫 사진에 립밤 중복 검출 1건이 남았다. 정상 박스 점수는 0.9870, 추가 박스는 0.5840이고, 두 박스의 IoU는 0.4277이다. 추가 박스는 점수 기준을 넘으면서 NMS 억제 조건에는 해당하지 않아 남는다. 정답과의 IoU는 각각 0.9698과 0.4155다. 이는 저장 예측 좌표를 분석한 결과이며 새로운 모델 추론이 아니다.

상대 위치·방향 지표와 비교 그림은 클래스별 최고 점수 박스를 사용한다. 따라서 위치·방향 통과와 추가 오탐은 동시에 발생할 수 있고, 선택 박스만 그린 그림은 중복 검출 전체를 보여주지 않는다.

200업데이트에는 립밤 오탐이 0건이었지만 집게 오탐이 11건이었다. 300업데이트에서는 집게 오탐이 0건이고 립밤 오탐이 1건이다. 추가 업데이트가 모든 오류를 단조롭게 줄인다고 볼 수 없다. 최종 결과에 맞춘 임계값 변경이나 자동 추가 학습은 하지 않았다.

## 재현과 적용 범위

원본 이미지·라벨·모델·실행 기록은 비공개로 보존한다. 공개 저장소의 [학습](../bounded-cv-training.md)·[평가](../checkpoint-evaluation.md) 도구와 [채점 규칙](../offline-cv.md)은 방법과 소프트웨어 검증을 재현하는 자료이며, 위 비공개 원본의 결과를 저장소만으로 독립 재현할 수는 없다.

인식 모델은 다음 시각 행동 학습의 보조 자산이다. 이 결과로 깊이·접촉·파지 성공·센서 없는 관절 제어 성능을 주장하지 않는다. 행동 파일럿은 별도로 명령과 팔 움직임을 연결해 평가한다.
