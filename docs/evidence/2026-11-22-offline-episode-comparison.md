# 명령 전 두 영상이 동작 결과 예측에 기여했는가

2026년 11월 18~21일 저장 자료를 재생했다. 물체 배치를 통째로 제외한 어깨 하강 시험에서는 명령별 평균이 두 영상보다 이동량의 크기를 더 잘 맞혔다. 부품과 평면 기구학을 추가하자 측면의 2차원 위치 오차는 줄었다. 같은 보강이 집게 영상에서도 이득을 준다는 증거는 없었다.

## 어깨 하강 후 상대 이동

예정 명령은 어깨 하강 70%, 420ms이며 정지 방식도 같은 사례끼리 비교했다. 시작 어깨각은 206.71~222.97°였다. 두 배치에서 각각 3건과 7건을 채점할 때 다른 배치만 학습에 사용했다. 실제 출력 기간 369~473ms, 구동 후 센서, OFF 후 두 쌍의 관측은 결과 검증과 학습 정답에만 사용했다. 사전 영상은 계획 시점에 도착한 영상이다. 카메라 간 광학적 동기화는 확인되지 않았다.

측면의 좌표는 물체 가로 중심·상단을 기준으로 한 턱끝이고, 집게 영상의 좌표는 양턱 중점을 기준으로 한 물체 위치다. 정답은 OFF 후 독립된 두 쌍의 좌표 중앙값에서 사전 좌표를 뺀 값이다. 아래의 쌍은 **측면 / 집게** 순서다.

| 예측에 사용한 정보 | 세로 방향 적중 | 이동량 크기 평균 절대 오차(px) | 2차원 이동 벡터 평균 오차(px) |
|---|---:|---:|---:|
| 무변화 | 0/10 · 0/10 | 18.27 / 2.80 | 18.27 / 2.80 |
| 같은 명령의 학습 배치 평균 | 10/10 · 10/10 | **2.98 / 1.41** | 4.74 / **1.55** |
| 예정 명령과 사전 양안 RGB | 10/10 · 10/10 | 3.17 / 1.51 | 4.68 / 1.63 |
| 같은 입력에 부품 가시성·상대 위치·어깨각·평면 회전 추가 | 10/10 · 10/10 | 3.18 / 1.51 | **3.23** / 1.63 |

가로와 세로 각각 ±1px를 정지로 두었다. 측면 **가로 방향** 적중은 무변화 3/10, 명령 평균 0/10, 양안 RGB 0/10, 보강 모델 **9/10**이었다. 측면 실측 세 건이 정확히 −1px로 정지 경계에 있어 이 적중 수는 허용폭에 민감하다. 집게 가로 이동은 10건 모두 정지 범위여서 네 방법 전부 10/10이었다. 10건의 실제 세로 이동은 두 영상에서 모두 같은 방향이었다. 크기 오차는 이동 거리의 차이이고, 벡터 오차는 예측한 종점과 관측한 종점 사이의 거리다. 배치 둘에 속한 연속 동작이므로 10개의 독립 배치로 해석할 수 없다.

6개 실행 기록의 계획 26건 중 14건은 다른 배치에 같은 명령·정지 프로필이 없었다. 2건은 출력 기간 이상 또는 두 번째 정지 후 관측 부족으로 결과를 확정할 수 없었다. 채점한 10건 중 1건에서는 보조 관측기가 집게 왼턱을 검출하지 못했다. 기존 관측의 상대좌표 정답은 있어 가시성 결측을 입력에 남겼다. 예를 들어 한 배치의 세 번째 하강에서 보강 모델은 측면 +16.45px, 집게 +2.02px를 예상했고 관측은 각각 +24.00px, +5.00px였다.

영상 모델은 각 카메라의 24×16 RGB 축소 영상으로 같은 명령의 훈련 사례 최대 세 건을 가중 평균한다. 보강 모델은 프레임별 턱·물체의 상대 위치와 가시성을 추가한다. 어깨에는 학습 배치의 센서 변화와 측면 턱끝 이동으로 평면 회전 중심을 추정해 잔차를 보정한다. 광각 부품 관측기는 아래 왕복 자료의 해당 구도에 적용했다. 이 실험에서는 물리 좌표계 전체의 카메라 보정을 식별하지 않았다.

## 날짜가 다른 손목·팔꿈치 펄스

11월 20~21일 네 수집 묶음의 29회에서 구도·예정 프로필·피드백 설정을 맞추고 수집 묶음 전체를 제외했다. 같은 조건이 양쪽에 있었던 프로필은 손목 올림·내림(부호별 PWM 120, 800ms), 팔꿈치 올림·내림(부호별 PWM 95, 550ms)이었다. 각 방향을 날짜별로 한 번씩 채점했다.

| 모델 | 측면 / 집게 세로 방향 | 측면 / 집게 가로 방향 | 이동량 크기 오차(px), 측면 / 집게 | 벡터 오차(px), 측면 / 집게 |
|---|---:|---:|---:|---:|
| 무변화 | 0/8 · 0/8 | 0/8 · 4/8 | 23.98 / 8.74 | 23.98 / 8.74 |
| 명령 평균, 양안 RGB, 부품·상대 위치 보강 (각각) | 8/8 · 8/8 | 8/8 · 8/8 | 5.32 / 1.41 | 5.35 / 1.55 |

각 학습 묶음의 같은 명령 사례가 단 한 건이어서 영상으로 이웃을 선택해도 명령 평균과 동일했다. 나머지 21건 중 18건은 다른 묶음에 같은 조건의 유효 사례가 없었고, 3건은 사전 또는 정지 후 두 쌍의 양안 라벨이 부족한 베이스 명령이었다. 어깨 배치 시험과 이 표는 수집 방식과 종료 관측이 다르므로 점수를 합산하지 않았다.

## 5축 왕복을 반응 학습에 쓸 수 있는 범위

11월 21일 버튼 시작 의도 25건 중 21건을 실제 출력에 연결했다. 거절 4건은 손목과 집게에서 각 2건이었다. 버튼을 놓을 시각은 시작 때 알 수 없으므로 예정 기간은 미상으로 유지했다. 구도·관절·방향·요청 세기별로 시작 어깨각, 사전 영상 쌍, 실제 출력과 OFF 후 관측을 연결하고 개발용 평균 반응을 계산했다. 다음 표에서 라벨 수는 시작과 OFF 후 양쪽 끝에 해당 측정이 있는 구간 수다. 집게 턱폭은 물체 중심 이동과 다른 관측량이다.

| 실제 관절 | 구도·요청 세기 | 시작 어깨각(°) | 시작 / 출력 연결 | 측면 턱끝 / 집게 턱폭 라벨 |
|---|---|---:|---:|---:|
| 손목 | 기존 50%, 70% | 215.94~216.03 | 8 / 6 | 0 / 3 |
| 팔꿈치 | 기존 70%, 광각 70% | 215.94~216.03, 219.46 | 4 / 4 | 3 / 4 |
| 어깨 | 광각 70% | 219.46, 187.73 | 2 / 2 | 0 / 2 |
| 베이스 | 광각 70% | 228.25 | 6 / 6 | 0 / 1 |
| 집게 | 광각 70% | 228.16 | 5 / 3 | 1 / 1 |

21건 모두 사전 영상 쌍이 있고 17건에는 OFF 후 0.3~2.5초 안에 다음 조작 전의 영상 쌍도 있었다. 측면 턱끝은 4/21건, 집게 턱폭은 11/21건에서 전후를 읽을 수 있었다. 측면 보류 17건, 집게 보류 10건에는 후속 쌍 자체가 없는 4건씩이 포함된다. 구도·방향·요청 세기를 유지하면 14개 프로필 모두 한 에피소드에만 있다. 왕복 중 인접 프레임을 분할해 독립 성능을 계산하지 않았다.

광각 팔꿈치 70%에서 측면 턱끝의 전후 이동은 내림 시 (+51, +245.5)px, 올림 시 (−49, −183.5)px였다. 각 한 번이고 실제 출력 기간도 3.957초와 4.249초로 달랐다. 이 차이만으로 유격을 추정할 수 없다. 기존 광각 기준점 대조에서도 높은 자세를 포함한 두 프레임의 위팔 8점 중 2점만 맞아, 표시된 부품 수만으로 턱끝을 확정하기 어렵다. 집게 닫기 중 59ms 출력에서는 측면 턱끝 변화가 0px, 집게 턱폭 변화가 +0.09px였다. 긴 닫기에서는 턱 검출이 끊겼다. 베이스에는 수동 관찰과 예상 좌우가 어긋난 기록이 있어 명령의 좌우를 실제 물리 방향으로 채점하지 않았다.

## 목표가 있는 시연의 행동 선택

11월 18일 같은 외부 카메라 구도의 사람 시연에서 **버튼을 누른 시점과 집기·놓기 목표가 주어진 상태**로 다음 관절·방향을 채점했다. 세부 단계는 점수 집계에만 사용했다. 각 열은 같은 조작 사례에 대한 적중 수다. 첫 조작이나 본 적 없는 이전 명령에서 기준선이 보류한 경우와 두 영상의 표가 갈린 경우도 분모에 포함했다.

| 학습·평가 분리 | 사례 | 직전 그대로 반복 | 직전 명령별 다음 최빈 행동 | 양안 결합 최근접 후보 | 양안 각각의 표가 일치할 때만 제안 |
|---|---:|---:|---:|---:|---:|
| 7편 중 매번 1편 제외, 집기 | 32 | 2 | 13 | 17 | 10 (보류 19) |
| 같은 분할, 놓기 | 15 | 1 | 12 | 13 | 9 (보류 5) |
| 앞의 7편만 학습, 별도 2편 집기 | 6 | 0 | **6** | 5 | 3 (보류 3) |
| 같은 별도 2편, 놓기 | 4 | 0 | 4 | 4 | 4 (보류 0) |

57건 모두 명령 전 양안이 있었다. 별도 두 편의 10건 중 7건에서 적어도 한쪽 영상의 촬영 시각 하한과 버튼 입력 사이가 0.69초를 넘었다(상한의 최댓값 1.19초). 이 점수는 동작 중 보정 시점이나 들기 성공률을 측정하지 않는다. 한 집기 사례에서 두 카메라가 모두 팔꿈치 올림을 제안했으나 사람은 어깨 올림을 골랐다. 별도 광각 자료의 집기 시연은 1편(4개 조작)으로 독립 집기 평가가 불가능했다. 기존 고정 광각 후보를 별도 놓기 시연에 적용한 기록은 양안과 직전 명령 기반 후보 모두 0/2였다. 놓기의 집게 열기는 학습한 행동 목록에 없었다.

## 기구학과 시뮬레이터에서 확인한 범위

- **MuJoCo**에서 실물 어깨 하강의 OFF 직전 센서 두 개로 속도를 추정하고, 구동을 끈 뒤 358ms의 관성을 계산했다. 실측 187.73°에 대한 오차는 0.746°, OFF 추정 각도를 그대로 유지한 오차는 0.603°였다. 상승의 OFF 추정 표시각은 약 142°로 모델 상한 90°를 넘어 보류했다. 실물 왕복 두 구간 중 1건의 정지 직후 검산이며 PWM에서 전체 이동을 예측한 결과는 없다.
- **FK·IK와 RViz**에서 같은 표시 자세의 FK와 MuJoCo 도구점이 수치 정밀도 안에서 일치했다. 기존 IK 분기는 관절 범위 위반을 반환했다. RViz의 다섯 관절과 URDF 축을 확인했다. 다른 관절각은 표시용 가정이고 영상과 실물의 축·영점 오차는 남아 있다.
- **Gazebo**에서 격리한 ROS2 명령을 브리지로 전달하고 관절 상태를 ROS2로 다시 받았다. 가상 어깨 목표 0.400rad에 반환값 0.390rad였다. 실제 모터 출력이나 물체 접촉 성능을 이 결과에서 추정하지 않았다.

## 재현

Python 환경에 NumPy·Pillow·OpenCV를 준비하고 시뮬레이션에는 MuJoCo를 추가한다. 다음 명령은 저장소 루트에서 실행한다. 인자는 각각 해당 실험의 보관 디렉터리와 시연을 등록한 촬영 계획이다. 원본 영상·출력 원장은 비공개 자료다.

```sh
python tools/offline_range_inventory.py "$MANUAL_RANGE" --archive "$CAPTURES" > range.json
python tools/offline_dual_response_comparison.py "$NEAR_GRASP" response.json
python tools/offline_field_response_comparison.py "$FIELD_SMALL" "$FIELD_MOTION" "$CURRENT_POSE" "$REAR_CORRECTION" --output field-response.json
python -m tools.offline_goal_action_comparison --episodes "$MANUAL_EPISODES" --plan "$POLICY_PLAN" --output action.json
python tools/offline_range_simulation.py --episode "$SHOULDER_RANGE" --model-dir "$VISUAL_MODELS" --anchor "$JOINT_REFERENCE" > simulation.json
```

## 다음 실험 하나

같은 광각 구도에서 앞·뒤 배치와 시작 어깨각을 기록하고, 재현 가능한 두 시작 조건 각각에서 **팔꿈치 내림과 손목 내림을 별도 에피소드로 실행**하는 대응 시험을 제안한다. 각 후보의 예정 프로필을 고정하고 실행 순서를 교대한다. 각 시행 전 두 영상으로 시작 상태를 확인하며, 실행된 후보의 측면 턱끝–물체 간격과 집게 중심 이탈을 OFF 후 재측정한다. 같은 목표에서 후보 순위가 바뀌는지, 보강 모델이 명령 평균보다 양쪽 종점 오차를 줄이는지를 보지 않은 배치에서 평가한다. 이 비교에 사용한 배치는 최종 실물 평가용 앞·뒤 배치와 별도로 관리한다. 새 촬영·구동과 현장 조건 확인이 필요한 실험이다.

현재 우선순위는 모방학습 후보와 반응 예측의 독립 평가다. VLM은 저장 프레임의 가림·단계 판독을 사람 라벨과 대조하는 데 먼저 쓸 수 있다. 강화학습의 보정 정책 비교는 PWM·자세별 이동과 정지 오차를 재현할 수 있을 때, VLA의 목표 조건부 선택은 같은 상태에서 집기·놓기 지시를 달리한 독립 시연이 있을 때 평가한다. 최종 실물 평가는 학습·조정에서 제외한 앞·뒤 배치를 각각 사용한다. 사람 개입 없이 모터 OFF 후 연속 독립 양안 4쌍에서 물체 위·아래가 모두 시작보다 20px 이상 올라 유지되는지가 성공 조건이다. 이 오프라인 실험에서 해당 성공 조건을 시험한 횟수는 0회다.
