# 2026-11-15 준비된 장면의 모델 선택 집기·들기·내려놓기·해제

[문서 색인](../README.md) · [시각 행동 학습](../visual-action-learning.md) · [프로젝트](../../README.md)

한 물체와 준비된 시작 자세에서 **모델 선택 닫기 3회 → 상승 1회 → 약 3.58초 공중 보유 관측 → 하강 1회 → 열기 1회**를 연결했다. 외부 영상과 집게 위 영상에서 물체의 탁상 이탈, 보유, 탁상 복귀와 해제를 별도로 판독했다. 이는 이번 조건의 한 시도이며 반복 성공률이나 수동 준비 없는 전체 자율 접근의 검증은 아니다.

## 조건과 역할

- 단일 분홍 기둥 물체, 탁상, 고정된 외부 카메라 구도와 집게 위 카메라를 사용했다. 외부 영상은 1920×1080, 집게 영상은 320×240이다.
- 사용자가 초기 ㄱ자 자세와 연결·전원·작업 공간을 준비하고 현장에서 감시했다.
- **상위 실험 진행 에이전트**가 관측 등록, 수동 수집의 방향·출력·기간 결정, 학습·모델 고정, 단계 전환과 실제 영상 판독을 맡았다. 이 문서의 수동 명령은 학습 행동 예측 모델이 선택하지 않은 명령이며, 사용자가 직접 버튼을 누른 횟수를 뜻하지 않는다.
- **학습 행동 예측 모델**은 각 모델 실행 단계에서 현재 영상 특징과 지원되는 예정 명령의 결과를 비교하고 행동 또는 STOP을 선택했다. 최종 구간에서도 각 실행 뒤 새 영상을 관측했다.
- 단계마다 다른 목적의 모델과 실행 경로를 사용했다. 전체 접근부터 해제까지 하나의 정책이 중간 개입 없이 자동 진행한 결과는 아니다.

## 마지막 연결 구간에서 관측한 결과

| 단계 | 모델 선택 명령 | 실제 결과와 판정 범위 |
| --- | --- | --- |
| 닫기 | M1 CLOSE 70%·1000ms, 3회 | 보이는 손가락 끝의 수평 간격이 약 137 → 122.54 → 79.61 → 49.70px로 감소했다. 고정 숫자 목표 35px에는 도달하지 않았고, 다음 예측이 실험 하한보다 작아 STOP을 선택했다. 이 숫자만으로 파지 성공을 판정하지 않았다. |
| 들기 | M3 UP 70%·1000ms, 1회 | 외부 영상에서 물체 하단과 탁상 사이의 공극이 나타났고 집게 영상에서도 물체가 양쪽 손가락 사이에 남았다. 물체 중심의 영상 상승은 약 57.38px, 표식에서 계산한 가상점 상승은 약 54.43px였다. 두 수치는 실제 높이의 mm 측정값이 아니다. |
| 보유 관측 | 추가 구동 없이 두 카메라 재관측 | 앞·뒤 두 관측의 보수적인 시간 간격은 3.582초였다. 그 두 관측에서 물체가 탁상에서 떨어진 상태로 집게와 함께 유지되는 것을 확인했다. 장기 보유나 파지력 검증은 아니다. |
| 내려놓기 | M3 DOWN 70%·1000ms, 1회 | 물체 중심이 영상에서 약 57.79px 내려왔고 물체 하단이 탁상에 다시 닿아 보였다. 저장한 들기 전 영상점으로의 복귀 예측과 실제 탁상 지지 판독을 구분했다. |
| 해제 | M1 OPEN 70%·1000ms, 1회 | 물체는 탁상에 서 있는 상태로 남았고 집게 영상에는 물체 양옆으로 벌어진 손가락 틈이 보였다. 열기 전·후의 보이는 끝점 간격은 약 49.79 → 95.59px였다. |

이 마지막 구간의 모델 선택 명령은 **6회**다. 각 구동 뒤 OFF를 확인했으며 마지막 해제 뒤에도 다섯 모터 OFF를 확인했다. 닫기 숫자 목표, 장치 명령 완료, 영상상 물체 상태와 실제 작업 판독은 서로 다른 결과로 기록했다.

자동 실행 기록의 `graspVerified`·`liftVerified` 등 보수적인 기본값은 성공으로 덮어쓰지 않았다. 위 작업 결과는 별도로 확인한 두 카메라 영상 판독이다. 최종 해제 뒤 전완과 집게 카메라의 영상 자세도 변했다. 해당 해제 출력 기록에서는 M1만 0이 아닌 출력을 냈으며, 자세 변화의 원인은 규명하지 않았다.

## 이번 작업 전체의 분모

마지막 6명령만 떼어 전체 작업의 성공률로 제시하지 않는다. 다음은 같은 날짜의 이번 ㄱ자 자세 작업 범위이며, 프로젝트 전체 과거 실험 누계와 다르다.

| 범위 | 명령 수 | 실행 기록상 완료 | 실행 후 실패 |
| --- | ---: | ---: | ---: |
| 학습 모델 외부에서 선택한 수동 수집 | 16 | 14 | 2 |
| 모델 선택 실행 전체 | 8 | 7 | 1 |

수동 16명령은 M3 9회, M4 3회, M1 CLOSE 2회와 OPEN 2회다. 이와 별도로 **출력 전에 중단된 미시작 2건**을 보존했다. 모델 8명령은 앞선 국소 접근 1회 완료, 기존 장치 목표각 경로 1회 실패, 마지막 닫기·들기·내려놓기·해제 6회 완료로 나뉜다. 완료는 실행·OFF·관측 기록의 상태이며 집기 성공 횟수가 아니다.

실행 후 실패한 수동 원본과 장치 목표각 실패를 완료 자료로 바꾸거나 성공 학습행으로 자동 편입하지 않았다. 미시작·실패 명령의 자동 재송도 수행하지 않았다. **관측된 작업 성공은 마지막에 연결한 한 구간**이며, 이를 100% 성공률이나 동일 조건의 반복 성공으로 해석하지 않는다.

## 모델과 관측의 역할

| 구성 | 사용한 표현·목적 | 남은 한계 |
| --- | --- | --- |
| 외부 영상의 표식 가상점 | 실제로 보이는 보라·청록 표식 쌍의 고정 좌표계에서 가상점을 계산했다. 새 영상에서 물체 중심과 가상점의 변화 및 영상 표식축 각을 얻었다. | 가상점은 실제 손가락 끝·파지점·깊이·접촉·충돌 여유의 측정이나 가려진 끝점의 복원이 아니다. |
| M1 닫기 모델 | 손가락의 보이는 끝점과 물체 중심을 관측하고, CLOSE/OPEN 전이를 별도로 학습했다. 첫 참조 영상 폭에서 정한 목표 간격과 실험 하한을 고정했다. | 보이는 물체 폭이 바뀔 때마다 더 작은 닫기 목표를 새로 만들지 않았다. 실제 접촉과 보유는 후속 실물 관측으로 확인했다. |
| 들기 전이 모델 | 완료된 M3 UP 원본 3건을 재감사해 절대 가상점·M4 실측각·영상 표식축 각에서 다음 변화를 예측했다. 시작점에서 영상 위쪽 80px의 고정 목표에 UP과 STOP을 비교했다. | 파지 하중을 검증한 학습 자료가 아니며, 무하중 관측에서 파지 후 상태로의 전이를 개발 가설로 명시했다. |
| 내려놓기 역응답 모델 | 같은 UP 원본의 사후→사전 변화로 역응답을 추정하고, 실제 들기 전의 저장 영상점을 목표로 DOWN과 STOP을 비교했다. | **직접 DOWN 학습 자료는 0건**이다. 중력·마찰·출력 꼬리·방향 비대칭이 같다고 검증한 모델이 아니다. 실제 탁상 복귀를 별도로 판독했다. |
| 해제 목표 | 탁상 지지 판독 뒤 기존 OPEN 학습 전이에 별도 해제 목표를 적용했다. | 닫기 목표를 해제 목표로 재사용하지 않았으며, 벌어진 간격만으로 실제 해제를 자동 확정하지 않았다. |

실행 전 입력은 그때 확보한 영상 특징과 동작 전 M4 센서값이다. 동작 후 영상과 센서는 학습 정답·사후 검증 근거로 분리했다. 명령 평균 변화 기준선과 STOP도 비교했지만, 이번 한 작업의 수행이 영상 상태 입력의 독립적인 성능 향상이나 기준선 대비 일반적인 우위를 입증한 것은 아니다. 학습 잔차를 예측 신뢰구간이나 실제 정확도 보장으로 표현하지 않는다.

- [집게 끝점 관측기 `NearGripperTipObserver`](../../learning/near_gripper_tip_observer.py)와 [회귀 테스트](../../tests/test_near_gripper_tip_observer.py): 보이는 끝점과 물체를 분리한다. v2는 물체와 양쪽 손가락 전체 윤곽의 영상상 겹침을 검사하며 기존 v1 관측 계약을 보존한다.

공개 테스트는 소프트웨어 계약과 합성 실행 경로의 검증이다. 비공개 실물 원본이 필요한 일부 검사는 원본이 없으면 건너뛰므로, 테스트 통과가 위 실물 작업의 재실행을 뜻하지 않는다. 실제 촬영 원본, 장치별 설정과 현장 실행기는 공개하지 않았으며 이 문서는 누구나 그대로 실행할 수 있는 완성된 실물 데모 배포본이 아니다.

다음 검증은 같은 제한 조건의 새 시작 상태에서 실패·미시작·개입을 포함해 반복 시도 수와 보정 명령 수를 비교하는 것이다. 무하중→파지 하중 전이와 UP→DOWN 역응답 가설의 검증, 해제 뒤 자세 변화의 원인 확인도 남아 있다.
