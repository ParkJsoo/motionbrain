# 유한 관측 요청 관문 — 2026-10-15

## 실측 전 고정한 계약

- 같은 anchor에서 현재 영상 최대 **5회**, anchor 준비 완료 뒤 **3000ms** 운영 예산.
- **20개 독립 요청**을 한 묶음으로 실행한다. anchor 획득 실패도 분모 20에 포함하며 **16/20** 이상이 유효 소비와 핵심 증거 저장까지 마쳐야 탐색적 사용 가능 기준을 통과한다. 성공 후 재촬영하지 않는다.
- 영상 **100ms**, anchor **15000ms**, 소비 검사→핵심 증거 저장 **250ms**. first-send 인과 상한·exact semantic anchor·기존 ROI 그대로 사용한다.
- 이전 영상 소비 나이 중앙값 114.44ms·저장 최대237.66ms를 참고하면 5회는 약 1.76초의 처리/저장 비용이다. 3초는 상태 조회·파일 준비 비용도 수용하는 유한 운영 한도다. 독립 표본 성공 확률이나 통계적 신뢰 보장은 아니다. 80%는 제한 수집의 사용 편의 탐색 기준이다.
- anchor 획득은 기존 최대8회 메타데이터 조회·1초 간격이다. 3초에 포함하지 않지만 요청→anchor·요청→소비·요청→핵심 종료·요청→terminal 반환에 모두 별도 명시한다. GET timeout은 4초이며 blocking I/O를 강제 취소하지 않는다. 늦게 반환한 I/O는 실패로 기록하고 다음 촬영0.
- 새 anchor는 다음 **독립 요청**에서만 확보한다. 요청 안에서 재획득하지 않는다. 신선도 초과만 재촬영하며 직전 저장 장벽 성공을 요구한다. 외관/identity 손실·HTTP 오류·취소·시간 역행·저장 실패/지연은 즉시 요청 종료다.
- 안전 상태/출력 불변 검증 실패·저장 오류·중단 시 평가 묶음도 중단한다. 미실행 요청은 성공으로 계산하지 않으며 20 분모를 유지한다.
- 이 수치는 비구동 shadow 관측용이다. `trainingEligible=false`, `controlEligible=false`. 미달 시 예산·기준을 바꾸거나 추가 최적화 시험을 자동 실행하지 않는다.

## 구현

`tools/probe_fast_observation.py --request-id <ID>`와 기존 causal fresh shadow 옵션을 함께 사용한다. 고정 20요청 평가/원본 검증은 `tools/evaluate_observation_attempts.py`를 사용한다. 기존 표본 probe의 기본 동작은 유지한다.

원본 JPEG는 Git에서 제외하며 공개 집계에는 요청별 결과와 검증 메타데이터를 제공한다.
