# 왕복에서 배운 팔의 움직임을 다른 시연과 닫기 직전 목표에 대조한 결과

왕복 시연의 구동 중 영상을 짧게 잘라 동작별로 부품의 이동을 측정했다. 광각 팔꿈치 왕복에서 추정한 회전을 별도 시연의 시작 자세에 적용하고, 기존 구도의 별도 명령 시험에서는 사람이 닫기를 누르기 직전의 양안 상태를 목표로 삼아 각 동작의 결과를 채점했다. 두 실험은 각자의 촬영 구도 안에서 수행했다.

## 왕복 동작의 중간 구간

11월 21일 시작 의도 25건 중 실제 출력 21건이 확인된 7개 에피소드를 사용했다. 두 카메라의 촬영 시각 범위가 모두 드라이버의 비영 출력 구간 안에 드는 원본 영상 쌍을 골랐다. 같은 동작에서 서로 다른 원본 쌍이 연속하고 두 카메라 각각에서 간격이 0.8초 이하일 때 부품별 이동을 계산했다. 기존 구도는 프레임에 연결된 당시 오버레이를 사용하고, 광각은 원본에 현재 부품 검출기를 다시 적용했다.

| 관절 | 구동 중 양안 쌍 | 구간 이동 측정 |
|---|---:|---:|
| 집게 | 23 | 21 |
| 손목 | 346 | 341 |
| 팔꿈치 | 133 | 129 |
| 어깨 | 123 | 121 |
| 베이스 | 67 | 62 |
| 합계 | 692 | 674 |

674개 구간 중 638개가 동작 중간이고, 9개가 직전 구동 방향을 뒤집은 동작의 첫 구간이다. 자세별 관측에 원래 에피소드와 구도, 방향, 요청 세기를 유지했다. 추적 가능한 항목에는 손목 표식·측면 턱끝·어깨 및 팔꿈치 하우징·집게 양턱 중점과 폭이 있다. 영상에 물체가 없거나 보이지 않으면 물체 상대 위치는 결측이다.

652개 시점에서는 직전 두 관측의 변위를 이용해 그 시점 이후에 노출된 다음 쌍을 예측할 수 있었다. 기존 구도의 팔꿈치 내림에서 측면 턱끝 오차는 직전 변위를 이어 쓰면 평균 2.66px, 직전 위치를 유지하면 22.55px였다(턱끝을 읽은 14건). 올림은 각각 1.08px와 15.43px였다(46건). 이는 진행 중인 동작의 다음 위치에 대한 점수다. 서로 인접한 구간은 같은 에피소드에 속하며 정지 뒤의 관성까지 검증한 값은 아니다.

### 손목의 세기를 바꿔도 짧은 반응이 전이되는가

기존 구도에서 손목 50% 시연으로 70% 시연을, 이어서 70% 시연으로 50% 시연을 예측했다. 진행 중인 손목의 방향은 고정하고, 목표 시차는 0.30초(실제 영상 시차 0.20~0.40초)로 두었다. 훈련 시연의 변위 속도에 요청 세기의 비율을 곱하는 선형 근사를 두 방법에 동일하게 적용했다. 직전 영상에서 손목–턱끝 축의 기울기와 집게 턱폭이 비슷한 사례 최대 5개를 선택하는 방법과, 그 방향의 평균 반응을 비교했다.

296개 시점 후보 중 측면 턱끝과 필요한 입력 라벨을 모두 갖춘 131개에서 다음 턱끝 위치의 평균 벡터 오차는 무변화 8.53px, 명령 평균 2.23px, 양안 자세 기반 1.70px였다. 측면 기울기만 사용하면 1.702px, 양쪽 특징을 쓰면 1.698px였다. 이 비교에서 개선의 대부분은 측면 자세에서 왔다. 집게 턱폭 128건에서는 무변화 0.19px, 명령 평균 0.20px, 자세 기반 0.21px였다. 두 독립 에피소드 사이의 세기 전이 시험이며 광각에서의 손목 위치나 접촉을 검증한 결과는 아니다.

## 광각 팔꿈치 왕복을 별도 시연에 적용

광각 70% 팔꿈치 내림 왕복의 시작 영상에서 팔꿈치 중심을 한 번 수동 지정했다. 각 시점의 색 표식과 이 중심을 잇는 선의 각도를 구해, 버튼을 누른 뒤의 시간에 따른 회전을 측정했다. 다른 시연에서는 명령 전 영상에서 검출한 팔꿈치 중심 주위로 **그 시연의 손목 표식**을 같은 각도만큼 회전시켰다. 평가 영상으로 회전량을 학습하거나 맞추지 않았다. 비교 기준은 손목을 그대로 두는 방법, 왕복에서 관측한 손목의 가로·세로 이동을 그대로 더하는 방법이다.

| 평가 시연 | 무변화 | 왕복의 픽셀 이동을 그대로 적용 | 시작 자세에 왕복의 회전 적용 |
|---|---:|---:|---:|
| 집기 중 팔꿈치 내림, 50% | 35.38px | 10.96px | **3.08px** |
| 놓기 중 팔꿈치 내림, 70% | 44.32px | 19.07px | **9.32px** |

각 행은 버튼을 누르고 있는 동안 0.5·1·1.5·2초에 가장 가까운 실제 측면 프레임 네 개에서 잰 평균 2차원 위치 오차다. 실제 프레임 시각에 해당하는 훈련 회전량을 보간했다. 출력 지속을 가정한 시간별 예측으로, 놓을 시점을 입력으로 쓰지 않았다. 50% 시연에도 같은 70% 회전 곡선을 적용했으므로 세기에 따른 반응 차이는 남는다. 두 시연 모두 별도 에피소드이지만 평가 시점 네 개씩은 독립 시행이 아니다.

손목 표식은 평가 시점 8/8에서 비교했다. 측면 턱끝은 시작과 평가 프레임 모두에서 위치가 확보된 사례가 1/8이었다. 그 한 점의 회전 예측 오차는 1.29px였다. 손목 표식은 팔의 이동 단서를 주지만 턱끝의 가시성, 접촉, 물체와의 거리는 별도 관측이 필요하다.

## 실제 동작이 닫기 직전 양안 상태에 가까워졌는가

사람 집기 시연 두 편의 닫기 전 원본에서 측면 턱끝–물체 상대 좌표를 물체 너비·높이로, 집게 영상의 물체–양턱 중점 상대 좌표를 턱폭으로 나누었다. 두 시연의 중앙값을 고정하고 평가 시점의 명령 전 물체 크기·턱폭으로 픽셀 목표를 복원했다. 기존 구도의 두 관측 방식 각각에 대해 참조 원본을 해당 방식으로 다시 측정했다.

측면은 목표까지의 2차원 거리, 집게에서는 가로 오차와 2차원 거리를 각각 계산했다. 양수는 명령 후 목표와의 거리가 줄었다는 뜻이다. 아래 두 값은 각각 다른 날짜에 실제 실행한 결과다.

| 관절·방향 | 측면 목표 거리 감소(px) | 집게 가로 오차 감소(px) | 집게 2차원 거리 감소(px) |
|---|---:|---:|---:|
| 손목 내림 | +27.45 / +30.59 | +0.57 / +0.03 | +11.70 / +12.34 |
| 팔꿈치 내림 | +17.43 / +32.00 | −1.81 / −2.83 | +5.88 / +7.56 |
| 손목 올림 | −23.84 / −26.46 | −0.57 / −0.36 | −10.06 / −10.99 |
| 팔꿈치 올림 | −16.44 / −17.46 | +1.50 / +1.96 | −5.35 / −3.36 |

측면 거리가 1px 넘게 줄고 집게 가로 오차 증가가 1px 이하면 성공으로 세었을 때 손목 내림은 2/2, 팔꿈치 내림은 0/2다. 허용폭을 2px로 바꾸면 팔꿈치 내림도 1/2가 된다. 두 동작 모두 집게 영상의 **2차원 거리**는 줄였다. 다른 시작 상태에서 실행했으므로, 같은 상태에서 손목이 항상 더 낫다는 순위로 해석하지 않는다.

손목·팔꿈치 8건 중 이 조건을 만족한 2건과 만족하지 않은 6건을 명령 평균·양안·부품 보강 모델이 모두 맞혔다. 무변화 기준은 긍정 사례를 0/2 맞혔다. 명령별 훈련 사례가 하나라 세 반응 모델은 같은 예측을 했다. 별도 어깨 하강에서는 측면 접근과 가로 유지가 10/10이었지만, 집게 영상의 2차원 목표 거리는 한 배치 3/3에서 늘고 다른 배치 7/7에서 줄었다. 전체 분모는 손목·팔꿈치 등이 포함된 29건 중 8건, 어깨 등이 포함된 26건 중 10건이다. 보류 사유와 원래 분할은 [기존 오프라인 비교](2026-11-22-offline-episode-comparison.md)에 있다.

사람이 직접 접근한 11월 18일 시연도 별도로 채점했다. 닫기 목표를 제공한 두 편을 제외한 앞선 다섯 편의 접근 명령 15건 중 8건은 같은 명령·세기의 다른 시연이 없고, 3건은 전후 라벨 부족으로 보류했다. 나머지 4건 중 3건이 실제 양안 조건을 만족했다. 명령 평균과 영상 기하 최근접 후보가 각각 4/4건을 올바르게 분류했다. 나중의 두 편에서는 접근 명령 2건 중 1건만 채점할 수 있었고 두 모델 모두 그 한 건을 맞혔다.

## 어깨 왕복을 가상 팔에 재생

5축의 실제 출력 21건에서 구동 직전 영상은 21건, 중간 영상은 18건, OFF 후 영상은 17건을 연결했다. 어깨 내림·올림의 시작·중간·끝에서 센서값을 원본 양안 영상, 부품 오버레이, MuJoCo 표시 자세와 연결했다. 6개 시점 중 측면 어깨와 팔꿈치 하우징은 4개, 턱끝은 3개에서 읽었다. 하강 중간에서 끝까지 센서 변화는 −15.91°, 영상의 위팔 투영각 변화는 −18.07°였다. 상승 시작에서 중간까지는 각각 +28.04°와 +23.69°였다. 구간별 방향은 맞았고 영상 투영각과 센서값의 크기에는 차이가 있었다.

다른 관절은 기존 표시 자세를 가정했다. 6개 중 5개의 어깨 자세가 MuJoCo 표시 범위 안에 들었고, 같은 5개 후보를 격리한 Gazebo에서 재생해 관절 상태·ROS 좌표 변환·RViz 표시를 확인했다. 도구 위치의 해석적 FK와 ROS 좌표 변환 간 최대 차이는 0.000000041m 이하였다. 마지막 상승의 표시각 140.11°는 모델 상한 90°를 넘어 보류했다. 분석용 IK의 한 가지 해는 여섯 시점 모두 관절 한계를 충족하지 못했다. 가정한 팔꿈치 표시각 −109°도 실제 제어용 모델의 ±90°를 벗어난다. 모델 사이 도구 좌표가 일치해도 실물 도구점의 위치 오차는 따로 측정해야 한다. OFF 후 관성에 대해서는 [직전 실측 대조](2026-11-22-offline-episode-comparison.md)에서 비교 가능한 하강 1건의 MuJoCo 오차가 0.75°, 정지 시 추정값 유지 오차가 0.60°였다.

다음 판별 대상은 손목과 팔꿈치 중 어느 쪽이 같은 광각 시작 자세에서 측면 거리를 줄이면서 집게 좌우 정렬을 유지하는가이다. 이번 결과는 손목 내림을 먼저 비교할 근거와 팔꿈치 내림에서 확인할 가로 오차를 제공한다. 광각에서 턱끝 관측과 취소 시각이 검증된 뒤 같은 자세·물체 배치를 복원해 두 후보를 별도 에피소드로 평가한다.
