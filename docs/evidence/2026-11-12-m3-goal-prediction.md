# M3 목표 부근의 자동 관측·학습과 고정 후 평가

[프로젝트](../../README.md) · [포트폴리오](../../PORTFOLIO.md) · [개발 관측 계약](../development-gripper-observer.md) · [유한 작업 실행](../batch-model-sequence.md)

2026-11-12 시작한 실험의 조건별 결과다. 목표는 열린 집게를 물체에 닿지 않는 목표 자세로 접근시키기 전에, 영상 상태와 예정 명령으로 결과를 예측할 수 있는 범위를 확보하는 것이다. 수집 성공, 모델 예측 통과, 실제 접근·집기·들기 성공은 별개다.

## 관측과 실행 조건

- 사람이 새로운 자세·배경을 설정하고 비접촉 목표를 지정했다. 기존 자세의 관측 계약을 그대로 적용하지 않았다.
- 집게 카메라 320×240 영상에서 물체의 보이는 색 영역 중심과 양쪽 턱끝을 관측한다. 상태는 물체 중심에서 턱끝 중점을 뺀 상대 XY와 영상상 턱끝 간격의 세 성분이다. 가려진 전체 물체의 중심, 깊이, 파지점, 접촉·힘을 의미하지 않는다.
- 같은 등록 구도·물체·다른 관절 자세에서 M3(팔꿈치) 올리기·내리기를 수집했다. M4 어깨의 센서 자세와 외부 영상의 고정 기준도 검사했다. 이 기록은 M5 좌우 회전이나 여러 관절 동시 동작의 검증이 아니다.
- 예정 출력·기간과 실제 출력 기간을 분리한다. 예정 기간이 같아도 HTTP 응답·정지 확인 지연으로 실제 출력 시간이 달랐다. 이를 힘 부족으로 단정하거나 출력을 자동 증량하지 않았다.
- 관측 범위·정지·실행 원장·원본 해시를 검사하며 자동 전이를 생성했다. 매 표본에 수동 좌표를 입력하지 않았다. 사람의 초기 설정·이동 여유 확인과 실패 후 개입이 있었으므로 전체 무개입 자동 운전으로 표현하지 않는다.

외부 카메라의 고정 기준은 작은 구도 변화에도 거절될 수 있다. 수집 중 카메라가 움직였을 가능성이 있는 구간은 보류했고, 기존 기준을 완화하지 않고 구도를 복원했다. 일반적인 카메라 이동을 자동 보정해 기존 모델에 적용하는 기능은 검증하지 않았다. 집게 영상의 유용한 변화 부족과 외부 고정 기준 불일치는 서로 다른 문제다.

## 조건별 고정 모델 비교

예정 출력·기간별로 자료와 모델을 분리했다. 아래 오차는 동일하게 지원되는 평가 행에서 세 성분 예측 오차 벡터의 유클리드 길이를 평균한 값이다. 성분별 MAE, 물리 거리, 관측기의 실제 위치 정확도와 다르다. 명령 평균은 학습 자료의 같은 명령 평균이며 무변화도 함께 비교했다.

| M3 예정 명령 | 학습 | 고정 후 새 평가 | 공통 지원 | 영상 상태·명령 ridge | 명령 평균 | 무변화 | 판단 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 35%·650ms | 20 | 12/12 | 11 | 1.375px | 1.809px | 13.603px | 당시 예측 수치 기준 통과. 목표 부근 내리기는 지원 밖이라 실행 보류 |
| 60%·450ms | 22 | 10/12 | 10 | 2.266px | 1.887px | 7.554px | 명령 평균보다 나쁘고 평가 미완료 |
| 60%·350ms | 18 | 12/12 | 11 | 1.074px | 1.341px | 1.834px | 내리기 지원 평가 2건으로 최소 4건 미달 |

350ms 학습 18건은 새 적격 전이 17건과 기존 같은 350ms 보정 전이 1건이다. 과거 전이는 학습에만 사용했고 고정 후 새 평가로 다시 세지 않았다. 새 평가 12건 중 올리기 1건은 입력 지원 범위를 벗어나 공통 비교에서 제외했다. 공통 11건은 올리기 9·내리기 2건이다.

650ms의 유효 수집 32건은 학습 20·평가 12건이다. 이전의 다른 조건 보정 3건은 이 학습에 섞지 않았다. 450ms는 35회 실행 시도 중 세 원본이 실패했고 유효 전이 32건을 학습 22·평가 10건으로 사용했다. 350ms 보강은 31회 RUN 시도 중 응답 확인 30회였으며, 응답 불명확 1회는 실제 움직임 확인으로 세지 않았다. 응답 불명확·사후 조회 실패 원본은 학습에서 제외하고 보존했다.

## 모델을 유지한 내리기 보완

350ms 모델을 재학습하지 않고 지원 범위 안의 내리기 4건을 추가 평가하도록 정했다. 구동 전에 입력 원본·역할을 고정했으며, 지원 상태로 맞추는 위치 조정 동작은 학습·평가에 편입하지 않았다. 이 보완은 지원 상태에 조건을 건 자료이므로 원래 평가와 합산한 수치를 무조건 표집의 일반화 성능으로 해석할 수 없다.

- 추가 RUN 응답 확인 18회 중 적격 원본 16건: 위치 조정 13건, 새 내리기 평가 3건. 나머지 두 원본은 조회 기한 초과와 촬영 저장 지연으로 실패했다.
- 보완 평가 **3/4건**의 오차는 ridge **1.614px**, 명령 평균 **1.793px**, 무변화 **5.629px**다.
- 기존 평가와 합산하면 **15/16건** 완료, 공통 지원 **14건(올리기 9·내리기 5)**이다. 오차는 ridge **1.190px**, 명령 평균 **1.438px**, 무변화 **2.647px**다.
- 완결성, 공통 지원 최소 14건, 방향별 최소 4건, 두 기준선 대비 10% 이상 개선, 오차 4px 이하를 유지했다. 완결성 미달이므로 **전체 미통과**다. 원래 12건 평가의 방향 부족 판정도 그대로 남는다.

실패한 동작은 자동 재전송하지 않았다. 별도로 허용된 위치 조정 재시도도 촬영 실패로 끝나 추가 실행을 중단했다. 이 마지막 원본은 출력 OFF를 확인했지만 사후 영상·학습 정답이 없으므로 성공 전이나 평가로 만들지 않았다.

## 후보 비교와 실제 성과

목표 직전 두 상태의 내리기 후보가 350ms 모델 지원 범위에 들어왔지만, 예상 목표 개선량은 약 **3.11~3.13px**로 최소 4px에 못 미쳤다. 마지막 상태에서도 ridge 약 **3.53px**, 명령 평균 약 **3.67px**여서 정지를 선택했다. 기준을 낮춰 실행하지 않았다.

**이번 실험의 모델 선택 접근·닫기·집기·들기는 0회다.** 수집·위치 조정과 고정 모델의 읽기 전용 후보 비교를 실물 제어 성공으로 합산하지 않는다. 후속 과제는 고정 모델의 미완료 평가를 유효한 새 조건에서 보완하고, 지원 범위와 목표 개선 여유를 확보한 다음 실제 접근을 별도로 검증하는 것이다.

## 저장 실패와 재현 한계

마지막 촬영의 한 프레임 저장은 **261.46ms**로 기존 **250ms** 제한을 넘었다. 실패 원본과 판정은 유지했다. 모터 OFF 상태에서 저장 단계 계측과 큰 파일의 캐시 우회 후 487프레임이 제한 안에서 저장됐고, 동일 페이로드 1,000회 교차 비교에서 저장 I/O 꼬리가 줄었다. 그러나 원래 지연을 재현하지 못했고 전체 촬영 p99도 개선되지 않아 원인 확정·재발 제거로 표현하지 않는다. [계측·검증 상세](../mac-direct-camera.md)를 따른다.

관측은 지정 색·보이는 턱끝·같은 촬영 구도에 한정된 개발 경로다. 원본 해시·디코딩·검은 영상·시각·출력 감사는 좌표 정확도나 물리적 즉시 정지를 보증하지 않는다. 같은 날·같은 장치·연속 자세의 평가이며 다른 구도·하중·물체로의 일반화는 미검증이다. 비공개 원본 영상과 모델은 공개 저장소에 포함하지 않는다. 재평가에는 원본과 해당 관측·분할 manifest가 필요하며, 공개 코드의 합성 회귀 검사와 실물 수치 재현은 구분한다.
