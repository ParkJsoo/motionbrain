## 구현 범위

- `learning/fast_observation.py`: 기존 객체 검출의 exact JPEG/hash·frame ID·ROI를 고정 기준으로 보존한다. 새 JPEG에서 정규화 템플릿 상관관계를 계산하며 기준 프레임과 측정 프레임을 별도 표시한다. 기존 검출 좌표의 hold를 새 측정으로 쓰지 않는다.
- `learning/fast_probe.py`, `tools/probe_fast_observation.py`: 기존 `ReadOnlyHTTP`, `DeviceReadAdapter`, `ArtifactStore`를 재사용한다. 원본 JPEG, HTTP 수신 기록, 각 성공/거부, 종료 기록, 소스 hash를 보존한다. 시작·표본별·종료 IDLE 확인과 시작/종료 출력 로그 비교를 포함한다. 실행 경로에 모터 명령은 없다.

## 다음 작업과 완료 기준

1. **비구동 지연 개선:** 측정 전 동기 기록의 비용과 영상 계산 비용을 분리해서 줄인다. 저장 순서/큐를 바꿀 때는 미기록·유실·중단을 표시하고, 처리 완료 시각과 소비 시각을 구분해야 한다. 작은 ROI만 검색해서 장면의 중복 후보 검사를 없애는 식으로 성공률을 높이지 않는다. 같은 정지 장면 반복 측정과 가상 이동·소실 회귀를 유지하며 실제 전체 나이 100ms 충족 여부를 다시 확인한다. 현재 결과는 이 완료 기준을 통과하지 못했다.
2. **사용자와 실물 시야 검증:** 모터 없이 컵을 조금 이동·가림·유사 물체 배치해 측정 오차와 거부를 확인한다. 현재 테스트는 합성 이동과 정지 실물 장면까지다. 파지 시 영상상의 목표 위치/크기는 별도 교정하며 영상 중심을 파지 위치로 간주하지 않는다.
3. **행동 수집 전 남은 연결:** 카메라 시각의 물리 검증·드리프트 한계, M4 측정 시각 구간, 명령 journal/MCU 결과 연결, 활성 UART/제한 실행·정지 실물 검증을 완료한다. 그 뒤 제한된 한 축 수집 및 행동 전후 데이터 적격성을 검증한다. 이번 구현이 이 단계를 대신하지 않는다.
