# M4 어깨 폐루프 검증 — 2026-06-28

[English](2026-06-28-m4-shoulder-closed-loop.en.md) · [포트폴리오](../../PORTFOLIO.md)

AS5600을 장착한 M4 어깨 한 축의 목표각 제어를 검증했다. 아래 값은 당시 고정 장착의 결과이며 현재 자세나 다른 네 관절의 정확도를 뜻하지 않는다. 검증 범위는 230–245°이고 더 넓은 펌웨어 소프트 범위의 안전성을 증명하지 않는다.

## 측정 구성

- AS5600 I2C 주소 `0x36`, SDA `GPIO0`, SCL `GPIO15`. [핀맵](../../PIN_MAP.md)
- analog OUT은 `raw=4095`, 약 3145mV에서 포화돼 제어 입력에서 제외했다.
- 초기 자석 정렬 실패는 `MD=NO`, `ML=YES`, magnitude 약 0으로 나타났다. 재정렬·고정 후 정상 자석 상태와 연속 각도를 확인했다.
- 재장착 때 원본 258.93°를 기존 좌표 234.58°에 대응시켜 장착 오프셋 −24.35°를 사용했다. 다른 장착에 재사용할 값은 아니다.
- 목표 합격 기준 ±0.50°, 센서 최신성 150ms, 명령 타임아웃 7초. 센서·자석 이상, 진행 없음, 안전 차단, 범위 위반 시 정지한다.

## 실패와 수정

| 발견한 문제 | 근거 | 수정 |
| --- | --- | --- |
| 출력 차단 후 관성 이동 | 상승 +0.88~+0.96°, 하강 −1.50~−1.59° | 방향별 정지 선행값을 두고 출력 차단 후 600ms 안정화 검사 |
| 실제 목표 미달을 성공 처리 | 234° 명령이 235.37°에 멈춰도 `TARGET_REACHED` 반환 | 안정화 후 오차 재검사, 제한 보정, 실패 시 `TARGET_MISSED` |

하중 실패 당시 센서와 다른 축 출력은 정상이었다. 무부하 관성 보상과 보정 펄스의 한계를 확인했지만 당시 전압을 측정하지 않아 하중·전원 영향을 완전히 분리하지 못했다. 실패한 실행은 최종 성공 표본에 합산하지 않았다.

## 최종 회귀

232–243° 목표·75/100% 명령 다섯 번과 238↔234° 왕복 여섯 번을 각 조건에서 수행했다.

| 조건 | 결과 | 평균 절대오차 | 최대 절대오차 | 최대 보정 | 모션 샘플 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 추가 하중 없음 | 11/11 | 0.132° | 0.36° | 2회 | 214 |
| 23.10g (500원 주화 3개) | 11/11 | 0.155° | 0.31° | 2회 | 201 |

두 조건 모두 기록 구간에서 안전 차단, IMU·AS5600 이상, 비-M4 활성은 0건이었다. AS5600 최대 나이는 무부하 36ms, 하중 39ms였다. 별도로 수행한 앞선 무부하 22/22는 최종 성공 기준 강화 전 결과이므로 이 표와 같은 버전의 반복 횟수로 합산하지 않는다.

## 전원과 부팅 복구

같은 23.10g 하중을 일반 멀티미터·휴대폰 영상으로 측정했다. 배터리 단자는 정지 5.97–5.98V, 상승 중 최저 5.86V였다. 별도 상승 실행의 XL4015 출력은 5.98→5.62V였다. 두 지점의 동시 측정이나 MIN/MAX 계측이 아니므로 약 2.0%·6.0% 강하는 근사치이며 전원 원인 확정 근거는 아니다.

STM32 MPU-6050 초기화 실패에서는 `imuError=0x20`, SDA LOW가 관찰됐고 모션을 차단했다. I2C 재초기화·버스 복구를 부팅 시 최대 네 번, 실행 중 5초 간격으로 재시도하도록 보강했다. 하드웨어 리셋 여섯 번과 전원 재인가 한 번 후 정상 복구를 확인했지만 배선·풀업·센서의 간헐 결함까지 배제하지는 못했다.

## 한계

- 한 축·고정 장착·작은 하중의 유한 시험이다. 장기 반복, 진동, 다양한 배터리 전압, 전 자세 간섭은 미검증이다.
- GPIO0/GPIO15 부팅 조건과 센서 장착 영점을 별도로 확인해야 한다.
- 출력 기록과 센서 각도 검증이며 전기적 비상 정지 시간·파지력·전체 관절 궤적 추종 시험은 아니다.
- 원본 계측·실행 기록은 로컬에 보존하며 공개 문서는 조건과 집계 결과를 제공한다.
