# 새 고정 모델이 선택한 M1 닫기 실물 시험

2026-11-13, 고정 구도에서 **모델이 CLOSE와 정지를 비교해 선택한 M1 닫기 1명령을 실제 실행하고 OFF 후 새 영상으로 닫힘을 확인했다.** 영상상 턱축 간격은 **126.677 → 113.767px**로 줄었다. 수동 등록 참조 목표 **85.3±1.5px에는 도달하지 못했다.** 단일명령 예산 종료이며 집기·들기는 시도하지 않았다.

## 관측과 실행 조건

집게 영상은 320×240이다. 영상의 row95에서 양 턱축의 유일한 어두운 구간 중심을 직접 측정하고, 주변 직선 구간의 품질 근거를 요구했다. 기존 row55 외삽 관측과 다른 등록 계약이며 이전 모델·수치 범위를 변환해 사용하지 않았다. 이 값은 영상 단면 간격으로, 실제 턱끝 간격·깊이·접촉·파지력의 측정이 아니다. 외부 영상으로 물체·전완의 고정 상태를 함께 검사했다.

목표 85.3px는 사람이 준비한 닫힌 자세의 **보이는 턱 구성 참조**다. 물체를 잡았다는 정답이나 기계적 닫힘 한계가 아니다. 새 관측의 실험 범위는 84~139.5px로 별도 선언했으며, 이 범위를 기계 안전 한계나 미래 결과의 보장 범위로 해석하지 않는다.

명령 요청은 CLOSE 60%·450ms였다. 드라이버 이력에서 실제 최대 PWM 크기는 **80/255**, 0이 아닌 출력 구간은 **582ms**였다. 램프와 정지 과정을 포함하므로 요청 비율·기간을 실제 출력과 동일시하지 않는다. 다섯 모터 OFF와 세션의 정상 종료를 확인했다.

## 예측·실측·기준선

고정 모델은 영상 간격 한 값과 예정 명령으로 간격 변화를 예측하는 ridge 모델이다. 실행 전에 CLOSE의 예상 목표 오차 29.731px와 정지의 41.377px를 비교해 CLOSE를 골랐다. 정지의 실제 반사실 결과를 관측한 비교 실험은 아니다.

| 항목 | 값 |
| --- | --- |
| 새 영상의 실행 전 간격 | 126.676957px |
| ridge의 실행 후 예측 | 115.031415px |
| 명령 평균의 실행 후 예측 | 114.756007px |
| OFF 후 새 영상 실측 | 113.766699px |
| ridge 절대오차 | 1.264716px |
| 명령 평균 절대오차 | 0.989308px |
| 무변화 기준 절대오차 | 12.910258px |
| 실제 목표 오차 | 41.376957 → 28.466699px |

**이 한 사례에서는 명령 평균이 ridge보다 정확했다.** 상태 입력의 추가 효과나 모델 우위를 입증하지 않았다. 모델이 선택한 실제 닫힘과 예측 모델의 기준선 대비 우위는 구분한다.

학습에 제공한 전이는 9건이며 OPEN 6건·CLOSE 3건이다. 명령별 최소 2건 조건에 따라 CLOSE450 3건, OPEN350 2건, OPEN450 2건의 모델 항목이 만들어졌고, 나머지 단일표본 명령은 실행 후보로 승격하지 않았다. CLOSE의 학습 입력 범위는 **125.823631~129.898706px**다. 고정 모델 SHA-256은 `1e884df2ce1d0c731d2d2e2772372edab4fe2b9cbb158d96535ebbaac63e1821`이며, 시험 중 재학습하지 않았다.

## 수동 준비·모델 시험·이전 실패의 분모

| 구분 | 분모와 결과 |
| --- | --- |
| 이번 새 관측 계약의 수동 수집·준비 | 9명령: OPEN 6, CLOSE 3. 실행·OFF·전후 관측 확인, 모델 선택 성과에서 제외 |
| 모델 고정 후 독립 실물 시험 | 1시험·1모델 선택 CLOSE 명령. OFF·새 사후 관측 확인, 목표 미도달 |
| 앞선 M1 수동 묶음 | 4명령 보존. 그중 사후 관측 거절 2건과 원래 실패 판정을 유지 |
| 이 일련의 M1 실물 명령 합계 | 수동 13 + 모델 선택 1 = 14명령 |

이 합계는 위 두 M1 묶음의 분모이며 프로젝트 전체 과거 M1 실험의 누계가 아니다. 기존 원본을 새 관측으로 사후 재처리한 개발 검증은 별도이며, 원래 실패를 성공으로 바꾸거나 독립 시험으로 다시 세지 않는다.

## 종료와 남은 한계

실제 시험은 처음부터 **최대 1명령**으로 고정했다. 최초 입력은 학습 지원 범위와 선언한 시작 구간 안이었다. 출력 OFF 후 3초 이후의 새 프레임으로 사후 상태를 측정했고, 학습 프레임을 재사용하지 않았다. 예측 잔차 3px와 실제 영상 범위 검사를 유지했다. 오류·자동 재전송은 0건이며 종료 상태는 `budget_reached`다.

사후 상태 113.767px는 다음 CLOSE의 입력 지원 범위 밖이다. 이를 새 명령 입력으로 재사용하거나 지원 범위를 늘리지 않았다. 따라서 **한 번의 모델 선택 닫힘은 확인했으나 목표 도달·다회 재관측 보정·반복 성공률·접촉·집기·들기는 검증하지 않았다.** 수동 준비를 포함한 전체 집기 동작을 모델이 완료했다고 주장하지 않는다.
