# 관찰 기반 대상 물체 잡기·놓기 — 2026-10-17

[포트폴리오](../../PORTFOLIO.md) · [데이터 계약](../data-pipeline.md)

소형 원통형 대상 물체 한 종류를 사용했다. 외부 카메라 화면을 관찰해 수동 명령을 선택하는 방식으로 최초 파지·들기를 확인한 뒤, 내려놓고 두 번 더 잡기·들기·놓기를 수행했다. 동작 선택에 외부 관찰과 사용자의 추가 시점 확인이 필요했다. 학습 정책이나 자동 시각 서보 제어가 수행한 시연은 아니다.

| 단계 | 기록한 새 구동 요청 | 관찰 결과 |
| --- | ---: | --- |
| 최초 놓기 | 5 | 물체를 내리고 집게를 연 뒤 빈 집게를 올림. 대상 물체는 서 있음 |
| 첫 반복 | 8 | 첫 들기 실패 후 닫기 보정1회로 들기·놓기. 분리는 다음 단계 첫 동작에서 확인 |
| 두 번째 단계 | 8 | 이전 분리 확인 포함. 계획한 닫기2회 후 들기·놓기·빈 집게 올리기, 추가 닫기 보정 없음 |

합계21회이며 공유한 분리 확인을 중복 계산하지 않는다. 두 번의 추가 시연 중 한 번은 보정이 필요했으므로 무보정 성공률·장기 반복 신뢰성으로 해석하지 않는다. 들기 높이와 파지력을 계측한 결과도 아니다.

각 새 요청의 종료 상태는 IDLE·모터5개 OFF·빈 큐였다. PWM 상한, 750ms 수동 명령 유효기간, 0.8s 요청 기준을 유지했다. 소프트웨어 출력 확인과 물리적 결과의 영상 판정은 구분한다.

## 자료와 한계

- 계획·결과21쌍, 외부 카메라 관찰 이미지21장, ESP32-CAM 이미지16장과 대응 응답을 비공개로 보존했다. 최초 놓기에는 CAM 이미지가 없다.
- 첫 들기 실패와 추가 보정도 보존했다. 공개 GIF는 별도의 6월 원격조작 시연이며 이 물체 파지 시연 영상이 아니다.
- 이미지37장은 비동기 관찰 스냅샷이다. 행동 경계와 동기화된 프레임, 검증된 광학 시각, 의미 기반 앵커가 아니다.
- 영상100ms·앵커15초·원본 저장250ms의 충족 여부는 미검증이다. **학습 적격 전이는0건**이다.
- 원본 보관의 무결성 통과는 로봇 작업 성공이나 학습 적격 판정을 대신하지 않는다.
