# 시각 행동 학습의 연구 근거

[동작 학습 설계](../visual-action-learning.md)

초기 검토는 2026-10-30이며, 2026-11-07에 시각 제어·저가팔 학습·파지 품질·시뮬레이터 실측 검증 원문을 새로 검색하고 적용 조건을 추가 확인했다. 로봇이 자신의 움직임과 명령을 연결해 배우는 연구를 중심으로, 논문의 실험 조건과 MotionBrain에 적용할 아이디어를 구분한다. 아래 구현 방향은 프로젝트의 설계 제안이며 해당 논문의 성능을 재현했다는 의미가 아니다.

## 영상 오차와 기구학을 연결하는 기본 제어

**Chaumette·Hutchinson, Visual Servo Control, Part I: Basic Approaches, IEEE Robotics & Automation Magazine, 2006.**

영상 특징의 목표 오차와 카메라 속도를 연결하는 상호작용 행렬을 설명하고, 영상 기반 제어(IBVS)와 추정한 3D 자세 기반 제어(PBVS)의 수렴·특이점·궤적 문제를 비교한다. 기본 식·점 특징의 깊이 의존성·상호작용 행렬 근사와 시뮬레이션 예를 확인했다. 영상에서 점이 목표에 가까워지는 것만으로 3D 경로가 좋거나 충돌이 없음을 보장하지 않는다. [원문](https://web.mit.edu/amcp/OldFiles/drg/Chaumette_Part_I.pdf)

MotionBrain에는 전체 팔의 기구학적 자코비안, 카메라의 영상 변화 관계, PWM·지속시간에 따른 실제 반응을 구분하는 기본 틀로 활용한다. 현재 제한된 유한 명령의 전이모델을 연속 속도 제어기의 식에 그대로 넣지 않는다. 먼저 일관된 특징점과 관측 실패 처리를 고정하고, 필요한 관절의 후보가 영상 오차에 미칠 결과를 비교한다. 외부 카메라는 전체 팔·작업공간, 집게 위 카메라는 국소 정렬을 관측하되 서로 다른 좌표를 보정 없이 합치지 않는다.

## 명령에 따른 움직임 관계

**Li 외, Controlling diverse robots by inferring Jacobian fields with deep networks, Nature, 2025.**

명령 변화에 로봇의 각 공간점이 어떻게 반응하는지 Neural Jacobian Field로 학습하고, 여러 구조의 로봇에서 영상 기반 제어를 시연했다. 학습에는 여러 시점의 영상(실험 구성 12대), 제어에는 단일 카메라를 사용했다. 준정적 동작을 가정하며 고속 과도 동역학 전체를 모델링한 결과는 아니다. [논문](https://www.nature.com/articles/s41586-025-09170-0) · [프로젝트·영상](https://sizhe-li.github.io/publication/neural_jacobian_field/) · [저자 코드와 2D 튜토리얼](https://github.com/sizhe-li/neural-jacobian-field)

MotionBrain에서는 명령 채널별 시각 이동의 민감도를 참고한다. 우선 단일 시점의 팔 특징점 변화와 PWM·지속시간 사이의 유한 움직임 모델을 만들고, 주변의 국소 관계를 살펴본다. PWM을 관절각 변화로 대신 넣거나 단일 카메라 파일럿을 원 논문 재현이라고 표현하지 않는다. 원 저장소의 3D 학습 환경은 CUDA 계열 구성으로, 현재 Mac에 그대로 적용 가능한지 검증하지 않았다.

2026-11-07에는 [공개 원문 v2](https://arxiv.org/html/2407.08722v2)의 방법·수집·제어 절을 다시 확인했다. 실험은 보정한 12대 RGB-D 카메라와 명령 후 정착 상태를 사용하며, 학습 후 단일 카메라 제어와 학습 시 다중 시점 구성을 구분해야 한다. 명령 변화에 따른 공간점 이동을 배우는 구조는 팔 전체에 유용하지만, 직접 PWM으로 구동하는 과도 상태·하중·접촉까지 같은 모델이 설명한다는 근거는 아니다.

## 행동 후 관측 예측과 계획

**Ebert 외, Visual Foresight: Model-Based Deep Reinforcement Learning for Vision-Based Robotic Control, 2018.**

로봇이 자율적으로 수집한 상호작용으로 행동에 따른 미래 영상을 학습하고, 목표 픽셀·목표 이미지 등을 기준으로 후보 행동을 선택한다. 실물 물체 조작과 학습 때 보지 않은 물체에 대한 실험을 제시한다. [논문](https://arxiv.org/abs/1812.00568) · [저자 코드](https://github.com/SudeepDasari/visual_foresight)

가져올 핵심은 예측→선택→실행→재관찰 과정이다. 첫 버전은 전체 영상 생성 대신 팔 특징점 변화 예측으로 축소한다. 공개 코드는 수집·계획·제어를 포함하지만 영상 예측 모델 학습은 별도이며, 오래된 Python 환경을 전제로 하므로 구조를 참고한다.

2026-11-07에 원문 §VI–VIII를 추가 확인했다. 후보의 학습 명령 범위 제한, 행동열 중 첫 행동만 실행하는 계획, 적절히 배치한 두 시점의 목표 결합이 특히 관련된다. 파지 자료 수집에는 손목 높이가 낮을 때 집게를 닫는 설계된 반사 동작도 사용했다. 이를 학습이 아무 사전 설계 없이 파지를 발견한 결과로 소개하지 않는다. MotionBrain의 두 카메라도 단순히 두 장을 확보하는 것과 보정·시각·목표를 일관되게 결합하는 것을 구분한다. 논문의 동적 재시도 방식을 현재 실패 명령의 자동 재전송 근거로 가져오지 않는다.

## 부정확한 몸체와 상태 변화에 적응

**Kawaharazuka 외, Self-Supervised Learning of Visual Servoing for Low-Rigidity Robots Considering Temporal Body Changes.**

저강성 MyCobot에서 스스로 물체를 놓고 같은 동작으로 다시 집는 수집 방식과, 영상·명령 시계열 모델을 이용한 시각 제어를 제시한다. 몸체·카메라 상태의 변화를 작은 내부 변수로 적응시킨다. 제어 입력은 목표 관절각이며 동작 재현성을 활용한다. [논문 공개본](https://arxiv.org/abs/2405.11798) · [네트워크·수집·실험 본문](https://arxiv.org/html/2405.11798v1)

MotionBrain에서는 최근 영상과 명령의 이력, 장비 상태에 따른 보정 아이디어를 참고한다. 처음부터 놓기·재파지 자동 수집을 전제하지 않고, 짧은 동작의 재현성이 확인된 뒤 검토한다. 목표 관절각 입력과 DC 모터 PWM 입력의 차이를 별도로 모델링해야 한다.

## 기존 제어와 학습한 보정의 결합

**Johannink 외, Residual Reinforcement Learning for Robot Control, ICRA 2019.**

기존 피드백 제어가 처리하는 부분에 강화학습의 잔차 출력을 더해 접촉·마찰의 영향을 보완한다. 실제 로봇의 블록 조립 실험을 제시한다. [논문](https://arxiv.org/abs/1812.03201) · [저자 프로젝트·영상](https://residualrl.github.io/)

MotionBrain에서는 기구학이나 영상 제어로 기본 움직임을 구하고, 보상으로 학습한 제한된 행동 보정을 더하는 후속 구조를 검토한다. 예측오차를 지도학습으로 보정하는 방법과는 구분한다. 처음부터 전체 제어를 강화학습에 맡기는 계획은 아니다. 저자 프로젝트에서 즉시 사용할 통합 코드까지 확인한 것은 아니다.

2026-11-07에 방법·실물 실험·한계 절을 다시 확인했다. 실물 Sawyer의 기본 제어는 부드러운 관절 impedance 제어이며, 물체 위치·각도 관측과 끝단 z방향 힘을 사용한다. 이미 집은 블록의 삽입이므로 초기 파지 자체를 해결한 사례로 옮기지 않는다. 현재 팔에는 같은 기본 제어와 접촉 관측이 없어 바로 도입하지 않는다. 기본 제어의 안정성만으로 학습 보정을 합한 전체 제어의 안전성이 증명되지도 않는다.

## 적은 상호작용에서 예측 불확실성 활용

**Chua 외, Deep Reinforcement Learning in a Handful of Trials using Probabilistic Dynamics Models, NeurIPS 2018 — PETS.**

확률적 동작 모델 앙상블과 궤적 샘플링으로 예측 불확실성을 전달하고, 후보 행동을 계획한다. 벤치마크에서 적은 표본으로 학습하는 효과를 비교했다. 제목의 적은 시도 수를 MotionBrain 실물 팔의 필요 데이터량으로 환산하지 않는다. [논문](https://arxiv.org/abs/1805.12114) · [저자 코드](https://github.com/kchua/handful-of-trials)

팔 특징점·사용 가능한 센서·명령 이력을 작은 상태 벡터로 만들고, 작은 모델 여러 개의 예측과 불일치를 비교하는 방법을 검토한다. 기존 공개 환경은 오래된 MuJoCo 기반이므로 알고리즘을 참고하며, 불일치 자체를 충돌 방지 보증으로 쓰지 않는다.

## 팔 전체 형태를 예측하는 자기 모델

**Hu, Lin, Lipson, Teaching Robots to Build Simulations of Themselves, Nature Machine Intelligence, 2025.**

로봇의 형태와 기구학을 학습한 자기 모델로 움직임 계획과 몸체 변화 대응을 연구했다. 공개 자료에는 고정 RGB 카메라와 관절 엔코더를 사용했다고 명시돼 있다. [논문 공개본](https://arxiv.org/abs/2311.12151) · [저자 코드](https://github.com/H-Y-H-Y-H/SelfSimRobot) · [데이터 설명](https://zenodo.org/records/14539921)

장기적으로 팔 전체의 공간 점유와 자세별 이동 가능성을 다루는 참고다. 현재 모든 관절각을 측정하지 못하는 MotionBrain에 곧바로 적용되는 카메라 전용 학습법으로 소개하지 않는다. 첫 2D 행동 모델 이후 시각 자세 추정과 결합할 후보로 둔다.

## 소규모 수집에서 가져올 판단 (2026-11-03)

**Deisenroth·Rasmussen·Fox, Learning to Control a Low-Cost Manipulator using Data-Efficient Reinforcement Learning, RSS 2011.** 자세 피드백이 없는 저가 로봇팔에서 깊이 카메라 관측과 확률 동작 모델로 제어를 학습했다. 초록·하드웨어·모델 절을 확인했다. 팔은 목표 서보 구성을 펄스 폭으로 명령하며, 물체를 집게에 미리 넣고 시작·목표 위치를 고정한다. MotionBrain의 직접 DC PWM·단일 RGB 영상과 다르므로 출력값이나 필요한 시도 수를 옮기지 않는다. 현재 상태와 명령에서 상태 변화를 배우되 관측·동작 불확실성을 함께 다룬다는 구조를 참고한다. [원논문](https://www.roboticsproceedings.org/rss07/p08.pdf)

2026-11-07에 III–V절을 다시 읽었다. 첫 네 서보의 목표 펄스폭을 제어하며 집게 닫기·손목 회전은 학습하지 않았다. 소수의 에피소드는 여러 시점의 상태 전이를 포함하므로 개별 전이 몇 개와 동등하지 않다. 장애물 비용은 충돌을 억제하지만 배제를 보장하지 않는다고 논문도 명시한다. 데이터 효율성의 참고이며 기존 출력 제한·정지 검사·이동 여유 확인을 비용함수로 대체할 근거가 아니다.

**Sukhija 외, Optimistic Active Exploration of Dynamical Systems, NeurIPS 2023 — OPAX.** 초록·문제 설정·가정 절을 확인했다. 잘 보정된 확률 동작 모델의 불확실성을 사용해 정보 획득을 목표로 탐색하며, 로봇 시뮬레이션에서 평가했다. 현재 MotionBrain에는 이 전제를 확인한 불확실성 모델이 없으므로 자동 탐색기를 바로 도입하지 않는다. 적은 수집에서도 서로 다른 후보의 반응을 구별할 수 있어야 한다는 설계 동기로만 사용한다. [원논문](https://proceedings.neurips.cc/paper_files/paper/2023/file/77b5aaf2826c95c98e5eb4ab830073de-Paper-Conference.pdf)

**Memmel 외, ASID: Active Exploration for System Identification in Robotic Manipulation, ICLR 2024.** 학회 공식 초록을 확인했다. 초기 시뮬레이터로 탐색을 설계하고 소량의 실물 자료로 시뮬레이터를 보정한다. 현재 팔의 검증된 시뮬레이터를 전제할 수 없어 알고리즘을 직접 채택하지 않는다. 실물 시도 수보다 얻을 정보와 후속 제어 목적을 함께 고려할 근거로 참고한다. 본문 PDF는 열람 도구의 크기 제한으로 확인하지 못했으므로 세부 성능 비교에 사용하지 않았다. [학회 초록·원문 링크](https://proceedings.iclr.cc/paper_files/paper/2024/hash/ae8afec5dabb07091d8f85128250f2ff-Abstract-Conference.html)

이 문헌들은 현재 측정 흔들림을 없애거나 특정 PWM의 이동·안전을 보장하지 않는다. 첫 묶음에서는 단순한 기준선과 소수 후보의 반응을 먼저 비교하고, 작은 신경망·가우시안 프로세스·자동 정보성 탐색의 추가는 별도 자료에서 이득을 확인할 후속 선택으로 둔다. 실행 전 예정 프로파일과 실행 뒤 실제 드라이버 기록도 구분한다. 새 수집 범위는 [유한 출력 프로파일 설계](../finite-output-profile.md#학습용-첫-수집-설계)에서 관리한다.

## 불확실성을 포함한 동작 학습 (2026-11-04)

**Chua 외, Deep Reinforcement Learning in a Handful of Trials using Probabilistic Dynamics Models, NeurIPS 2018 — PETS.** 원논문 초록·도입·확률 모델 및 불확실성 구분 절을 새로 확인했다. 상태와 행동에서 다음 상태의 분포를 예측하고, 관측·동작 잡음과 자료 부족으로 인한 모델 불확실성을 구분한다. 분포 출력과 모델 앙상블을 결합한다는 구조를 참고하되, 한 표본으로 신경망이나 앙상블을 적합할 근거로 사용하지 않는다. 논문에서도 적은 자료에서 표현력이 큰 모델의 과적합을 다룬다. [원논문](https://papers.neurips.cc/paper/7725-deep-reinforcement-learning-in-a-handful-of-trials-using-probabilistic-dynamics-models.pdf)

**Amadio 외, Model-Based Policy Search Using Monte Carlo Gradient Estimation with Real Systems Application, IEEE Transactions on Robotics 2022 — MC-PILCO.** 원논문 초록·부분 관측 상태의 추정 절·실물 실험의 필터 논의를 새로 확인했다. 실제 실행의 인과적 상태 추정과 오프라인 추정을 구분하고, 정책 학습에서 관측 장치와 온라인 추정기의 특성을 함께 모델링한다. 노이즈를 줄이는 필터도 지연과 왜곡을 만들어 학습·실행의 불일치를 일으킬 수 있다는 반례가 중요하다. 논문의 장치·표본 수·성공률을 MotionBrain 성능으로 옮기지 않는다. [원논문](https://arxiv.org/html/2101.12115v4)

MotionBrain에는 완벽한 계측을 기다리기보다 줄일 수 있는 검출 변동을 제한적으로 개선하고, 남는 변동을 확률 동작 모델에 반영한다는 가설로 적용한다. 방법 이름이 머신러닝·딥러닝·강화학습이라고 해서 실제 움직임과 측정 오차가 자동으로 분리되는 것은 아니다. 현재 영상·예정 명령에서 다음 상태를 배우는 지도 동작 모델을 먼저 만들고, 그 예측을 목표 접근의 명령 선택에 연결한다. 시범 행동 자료를 전제로 하는 모방학습이나 보상 기반 정책 학습은 별도 선택이다. [저장 영상 비교와 다음 관측 계약](../finite-output-profile.md#관측-변동-축소-실험과-남는-불확실성)

2026-11-07에 PETS의 §3–7과 부록의 모델·계획·비교 실험을 추가 확인했다. 확률망이 내는 분산은 자료 밖에서 임의적일 수 있으며, 소량 자료의 과적합 문제도 남는다. 앙상블이나 분포 출력을 추가했다는 이유만으로 신뢰구간·안전확률이 보정되는 것은 아니다. 반대로 복잡한 벤치마크에서는 선형모델의 한계도 보여 주므로, 작은 선형모델을 팔 전체의 영구 해법으로 고정하지 않는다. [공개 원문](https://arxiv.org/html/1805.12114)

## 정렬 이후의 파지 품질과 실제 보유

**Mahler 외, Dex-Net 2.0: Deep Learning to Plan Robust Grasps with Synthetic Point Clouds and Analytic Grasp Metrics, RSS 2017.**

초록·§III 문제와 가정·§V 실물 평가 구성과 지표를 확인했다. 깊이 영상과 평행 집게 후보의 위치·각도·깊이를 입력으로 파지 강건성을 예측하고 후보를 순위화한다. 알려진 카메라 내부 파라미터와 집게 형상, 단일 물체·작업면 가정이 있으며 대규모 합성 자료를 사용한다. 실물 평가는 들어 올리고 옮기고 흔든 뒤의 보유를 사용하고, 시도 전체 성공률과 모델이 강건하다고 선택한 경우의 정밀도를 구분한다. [저자 공개 원문](https://goldberg.berkeley.edu/pubs/dex-net-2.0-Camera-Ready-RSS-2017.pdf)

MotionBrain에는 접근·정렬을 위한 움직임 예측과 접촉·보유를 판단하는 파지 품질을 구분하는 근거다. 현재 RGB의 물체 중심·양턱 점만으로 깊이·마찰·접촉 힘이나 성공 확률을 계산할 수 있다고 해석하지 않는다. 초기에는 실제 접촉·보유의 별도 관측과 실패·보류 분모를 유지하고, 형상·깊이·집게 특성을 확보한 뒤 후보 파지 품질 모델을 검토한다. 논문의 흔들기 평가를 현재 장치에 즉시 실행할 계획으로 옮기지 않는다.

## MuJoCo 등 시뮬레이터의 실측 검증

**Acosta·Yang·Posa, Validating Robotics Simulators on Real-World Impacts, IEEE Robotics and Automation Letters, 2022.**

§III–VII의 실측 구성·파라미터 식별·평가·한계를 확인했다. 큐브 투척은 Drake·MuJoCo·Bullet, Cassie 착지는 Drake·MuJoCo로 접촉 재현을 비교했다. 큐브에서는 MuJoCo의 오차가 다른 두 도구보다 컸지만 Cassie의 큰 운동은 잘 재현했으며, 하나의 궤적을 맞추는 파라미터가 전체 자료에서 최선인 것도 아니었다. 특정 시뮬레이터의 보편적 우열로 해석하지 않는다. [공개 원문](https://arxiv.org/html/2110.00541)

MotionBrain에는 전체 팔의 링크·관절축·충돌 형상·카메라 프레임을 먼저 구성하고, 모터 명령과 실제 반응·하중·마찰·지연을 구분해 식별한 뒤 보류 실측으로 검증하는 순서가 적절하다는 근거다. MuJoCo를 설치하거나 시뮬레이션에서 집었다는 사실은 실물 파지·접촉 안전의 검증이 아니다. 관성·구동·접촉이 미검증인 초기 모델은 좌표·기구학·명령 경로의 오프라인 시험에 한정한다.

## 전체 팔 적용 우선순위 (2026-11-07)

다음은 위 문헌에서 도출한 프로젝트 적용 가설이며 새 실물 성능의 보고가 아니다.

1. **지금:** 시각 서보 제어의 특징·목표 오차 정의와 Visual Foresight의 예측→후보 비교→한 단계 실행→재관측 구조를 참고한다. 관측 표현·반올림·검출 실패와 모델 지원 범위를 먼저 분리하고, 고정 후 별도 평가를 유지한다. 관측 표현만 바꿔 기존 거절을 해제하지 않는다.
2. **첫 집기 연결:** 필요한 관절만 순차적으로 사용하며, 전체 팔의 위치 조정과 집게의 개폐 반응을 구분한다. 기존 FK/IK의 링크·축·좌표 가정을 실측과 비교하고 국소 학습 모델을 결합한다. 추가 관절 이동은 현재 자세·목표에서 필요성이 확인된 경우에만 포함한다. 파지 진입 확인과 실제 접촉·보유 결과는 구분한다.
3. **기록·시각화:** 전체 팔 관측·명령·예측·오차를 Rerun, 좌표·링크와 사용 가능한 실측 자세를 RViz, 모델·자료·평가 버전을 W&B에 연결하는 것을 검토한다. 추정 자세와 센서 실측을 구별하며 도구 도입 자체를 모델 성능으로 세지 않는다.
4. **후속:** Gazebo·MuJoCo의 전체 팔 모델은 기구학·명령 경로 확인부터 시작한다. 구동·접촉 모델을 보류 실측과 비교한 뒤 시뮬레이션 정책 학습을 검토한다. 신뢰할 기본 제어와 접촉 관측이 마련되면 Residual RL, 자료와 상태 표현이 충분해지면 PETS·가우시안 프로세스 기반 불확실성 모델을 별도 기준선과 비교한다.
